## 构建

需要 Windows 10/11 x64、Rust stable（MSVC 工具链）和 Visual Studio C++ Build Tools。

```powershell
cargo test --workspace
cargo run -p jiuheng-desktop
cargo build --workspace --release
```

开发或安装包冒烟测试可用 `JIUHENG_DATA_DIR` 指向隔离的数据目录；正常运行不设置该变量，数据仍写入 Windows 当前用户的本地应用数据目录。

安装包由 `scripts/build-windows.ps1` 生成。构建脚本只打包已验证的 release 可执行文件和必需资源。磁盘空间较小时可指定独立构建目录：

```powershell
.\scripts\build-windows.ps1 -TargetDirectory "D:\CodexBuild\jiuheng-target"
```

地点种子可由 GeoNames 官方 `CN.zip` 解压出的 `CN.txt` 确定性重建；生成器会拒绝猜补父级或中文名称不完整的记录：

```powershell
python .\scripts\build-location-seed.py --source C:\path\to\CN.txt --download-date 2026-08-30
```

乡镇街道名称种子由固定版本的国家地名信息库整理快照与上述 GeoNames 中心坐标确定性关联；完整来源、校验和与未匹配拒绝口径见 [地点库审计](docs/LOCATION_STREET_CATALOG_AUDIT.md)：

```powershell
python .\scripts\build-street-seed.py --source C:\path\to\regions_20260304_173812.json
```

## 重要边界

- “古法依据等级”只描述传统文献证据强弱，不代表现实概率。
- 健康内容仅作传统文化推演，不能用于诊断、治疗或生死决策。
- 历法/天文基础层在达到边界安全测试要求前，不会驱动术式规则。
- 本项目不含联网、登录、云端 API 或生成式 AI 功能。
