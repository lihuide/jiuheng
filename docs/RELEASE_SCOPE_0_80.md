# v0.80.0 首发范围与候选评审

日期：2026-11-12。定位：Windows 六爻排盘记录试用版。

本次按用户同意的方向，将可交付目标固定为：锁定问题 → 六次起法 → 普通界面阅读排盘 → 保存并重新打开 → 复制或导出离线报告。九术完整占断仍是后续目标，既有其他术式入口保留。

## 本轮候选评审结果

六爻降雨候选暂缓作为首发必备功能。现有原页不能直接支持任意现代目标时段内“不下雨”；增加月破、旬空、六合等排除项也不能补上时段依据。相反断语的优先关系、旺衰与暗动层次、伏神适用仍未审定。本轮不再扩充这些排除项，也不改变正式规则门禁。

比较现有候选：

| 交付候选 | 已具备 | 未满足 | 本轮决定 |
|---|---|---|---|
| 六爻降雨占断 | 两版原页、结构检查 | 时段依据、冲突解释、独立复核 | 暂缓作为首发门槛 |
| 蓍草起法及解释 | 十八变研究重建 | 依赖原典与独立复核、解释与应期 | 保持研究入口 |
| 梅花时间起卦及解释 | 取数机械结构 | 时辰/闰月口径、体用解释与复核 | 保持研究入口 |
| 六爻排盘记录 | 六次起法、八宫/纳甲/六亲/六神机械层、本地重放 | 普通界面完整报告、导出、历史查找体验 | 本轮完成，作为有限功能试用版 |

这次范围决定没有生成正式 Rule ID。结构说明是对已有程序计算的解释，不是古籍断语或预测结果。

## 后续正式规则工作的进入条件

先提交一张候选评审表，列出主版本原页、可执行前提、例外、输出含义、支持的时间范围及不适用情况；再决定是否开发。没有时段依据就不能承诺时段结论，没有建议依据就不能添加行动指令。

书目复核核对馆藏与版本；转录复核逐字比对主文及例外；逻辑复核解决冲突与范围；实现复核用正例、反例、边界和历史案例检验程序。独立复核人目前未落实，不把同一轮自查或代码测试登记为独立复核完成。

重新启用降雨候选必须先取得上述未决问题的有据判断。一次集中评审仍不能确定适用边界时继续暂停，转而评估条件更明确的候选；不为增加规则计数删除限制或制造结论。

## 进度口径

试用流程的完成与原始九术完整产品分别验收。16 项原始需求仍为 5 项通过、9 项进行中、2 项受阻；正式规则 0 条，完整可裁决术式 0/9。发布时另外记录本次新增用户功能和实际验证结果，不换算总体百分比。
