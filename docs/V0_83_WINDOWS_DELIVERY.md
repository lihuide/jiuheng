# 九衡 v0.83.0 Windows 交付

日期：2026-11-12。范围：梅花时间盘与奇门地盘接入普通排盘记录流程。

## 本次完善

- 新增“梅花 / 奇门机械盘”页面，侧栏、起法页和历史详情均可进入。无需出生资料或先摇六次铜钱，按原占问时间及地点展示。
- 梅花完整显示年/月/日/时取数过程、除八与除六的结果、本卦、变卦及动爻，使用已保存候选。中爻结构是从保存卦象派生的原始观察，明确未选互卦口径。
- 奇门以九宫图展示已保存的三奇六仪地盘、所隐甲、旬首地盘宫、本旬值符身份和值使取门宫。中五寄坤二取门时分别标出原宫与取门宫；没有把这些身份写成当前时刻的逐时星门落宫。
- 北京时间与真太阳时始终并列。梅花闰月不硬算；奇门处暑局数异文不生成地盘；旧快照缺字段保持缺失，临界时间保留提示。
- 两项支持全部候选复制及离线 HTML 导出、打印；文件名独立，创建新文件，不覆盖已有报告。
- 打开报告先核对快照哈希，再按原锁定输入复算梅花与奇门字段。支持原有快照版本及奇门早期字段兼容，不改写旧记录。数据库 schema 13、顶层快照 v30、出生审计 v14 保持不变。

本轮复用已经存在的梅花取数和奇门地盘算法，新增的是普通使用页面、报告和校验流程。原研究来源与范围见 [梅花起卦审计](MEIHUA_TIME_CAST_AUDIT.md)、[中爻观察审计](MEIHUA_MUTUAL_RAW_AUDIT.md)、[奇门地盘审计](QIMEN_EARTH_PLATE_AUDIT.md)和[奇门本旬身份审计](QIMEN_DUTY_IDENTITY_AUDIT.md)。
