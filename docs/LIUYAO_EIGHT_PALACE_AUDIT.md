# 六爻八宫卦序与世应机械层审计

## 本版完成范围

`jiuheng.liuyao.received_eight_palace_host_response.v1` 只接收已经完成重放校验的六爻本卦六位阴阳结构，并派生：

- 八宫：乾、震、坎、艮、坤、巽、离、兑；
- 宫内阶段：本宫、一世、二世、三世、四世、五世、游魂、归魂；
- 宫五行；
- 世爻与应爻位置。

程序按初爻为最低位。相对本宫纯卦的八个变爻掩码固定为 `0, 1, 3, 7, 15, 31, 23, 16`；世爻依次为 `6, 1, 2, 3, 4, 5, 4, 3`，应爻始终与世爻相隔三爻。八宫每宫八卦合计覆盖全部 64 个六位结构，自动测试要求每个结构只出现一次，并逐格核对传本六十四卦序号。

## 证据边界

本轮使用的《京氏易传》《易学象数论·占课》和《增删卜易·八宫图第三》均为公共电子转录。它们足以建立一个可检查的传世机械候选和交叉锚点，但尚未完成本地影印页字节固定、逐页 SHA-256、异文校勘与京氏原法/后世火珠林法的版本谱系拆分。

因此本实现准确命名为“传世八宫世应机械候选”，不宣称已经证明它就是无争议的汉代京房原法，也不把电子转录直接升级为正式规则证据。

机器可读证据、禁用项和未决问题保存在 `data/research/liuyao-eight-palace-host-response-candidates.json`。

## 运行与历史复现

六次三币完成并写入 SQLite 前，原始转录仍须先通过原算法重放。八宫与世应只在本卦重放成功后派生，不修改旧记录、随机种子、转录哈希或数据库模式。

新起卦页、开发者页和历史一键重放均显示所属宫、阶段、宫五行、世爻和应爻。旧记录也由保存的六位结构按同一版本重新派生，所以不会静默改写历史数据。

## 明确未实现

以下内容全部保持 `false` 或失败关闭：

- 纳甲天干地支；
- 六亲、六神、伏神；
- 用神、月建日辰、旺衰、动变；
- 吉凶、成败、应期、中间信号和行动建议；
- 正式 Rule ID 与综合裁决参与资格。

八宫归属、宫五行或世应位置本身不得直接生成占断。只有底本、原文定位、异文、四类复核和当前测试套件全部闭合后，后续规则才可独立申请准入。

## 自动护栏

- 核心测试穷举全部 64 个位图，验证八宫/阶段一一对应。
- 逐宫核对 64 个传本卦序号。
- 核对八类世应位置与八宫五行。
- 研究门禁逐项对拍 JSON 和核心输出，并要求正式规则包仍为空。
- 历史重放测试要求六爻证明包含相同位图的八宫审计，且纳甲、解释和规则资格均为否。
