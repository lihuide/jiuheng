# 中国古代星占结构目录审计

## 本版完成范围

0.26.0 新增共享二十八宿身份目录。0.47.0 在不改变其 v1 次序的前提下，加入三垣和日月五星身份目录；当前综合结构算法版本为：

`jiuheng.chinese_astrology.received_structure_identity.v2`

程序固定保存：

- 角起、轸止的二十八宿连续次序；
- 东、北、西、南四方各七宿；
- 苍龙、玄武、白虎、朱鸟四象身份；
- 通行短名及《晋书·天文志》所见南斗、牵牛、须女、营室、东壁、觜觿、东井、舆鬼、七星等长名；
- 算法版本、结构状态和全部失败关闭标志。

0.47.0 另固定保存：

- 《步天歌》公共转录所见的紫微、太微、天市三垣名目；
- 分别保存传本文字中的中元、上元、下元标签，但不据此重排目录；
- 日、月、岁星、荧惑、填星、太白、辰星七个天体身份；
- 岁星木、荧惑火、填星土、太白金、辰星水的传统对应；
- “七政”存在多种古解释，因此代码和档案始终用“日月五星身份目录”限定本项含义。

四方宿序固定为：

```text
东方苍龙：角 亢 氐 房 心 尾 箕
北方玄武：斗 牛 女 虚 危 室 壁
西方白虎：奎 娄 胃 昴 毕 觜 参
南方朱鸟：井 鬼 柳 星 张 翼 轸
```

这是身份目录，不是动态星盘，也不是星占规则。

## 文献边界

《晋书》卷十一“二十八舍”按东方、北方、西方、南方逐宿连续列出完整结构，是本版直接使用的主要转录线索。《史记·天官书》用于交叉确认东宫苍龙与早期宿序传统。《尚书·尧典》的星鸟、星火、星虚、星昴只作为更早的中星背景，不被扩写成它没有提供的完整宿表。《汉书·天文志》仅帮助界定中国古代天文占候对象的历史范围。

目前这些公开页面仍属于电子转录或检索入口，尚未全部绑定本项目独立核验的影印版本、具体册页和文件哈希。因此它们足以形成无解释的结构目录，但不足以直接放行占辞。

三垣以《步天歌》公共转录的“中元北极紫微宫”“上元天庭太微宫”“下元一宫名天市”为直接传本线索。这里不把网页署名直接当成已经完成的作者、年代或版本结论，也不从三句话扩写垣墙星数和成员。五星名称以《史记·天官书》为早期主线索，并以《汉书·天文志》交叉；隋萧吉《五行大义》用于明确记录“七政”多义以及日月五星、五星五行这一候选解释。全部仍只用于身份目录。

完整来源、支持范围和限制保存在：

`data/research/chinese-astrology-twenty-eight-mansions-catalog.json`

`data/research/chinese-astrology-three-enclosures-seven-luminaries-catalog.json`

## 明确没有实现

本版没有：

- 把二十八宿强行等分为二十八个现代黄经区间；
- 选择历代某套距星、宿度或坐标体系作为唯一古法；
- 映射到白羊、金牛等西方黄道十二宫；
- 计算月球、五星、日月食、客星、彗孛的动态位置；
- 实现三垣边界、左右垣成员、垣内星官、分野或完整宿外星官目录；
- 从古籍占辞生成 Rule ID、吉凶、应期、中间信号或综合裁决。

`enclosure_boundary_model_selected`、`angular_boundary_model_selected`、`celestial_positions_calculated`、`interpretation_eligible` 和 `rule_eligible` 在本版全部固定为 `false`。

## 快照与兼容

每次锁定占问都会把结构目录、算法版本和失败关闭状态写入不可变天文审计快照。二十八宿目录在顶层快照 v17 首次加入；0.47.0 将顶层快照由 v21 升到 v22，并写入三垣和日月五星目录。v1–v16 缺少整个星占目录、v17–v21 只有二十八宿目录时，都按原始 JSON 读取；程序不会补造字段、重写历史字节或改变旧哈希。

开发者模式对 v22 记录重算完整 v2 目录；对 v17–v21 记录只按旧 v1 字段核对。任何本应固化的名目、次序、对应或关闭标志变化都会导致重算不一致。

## 进入正式星占规则前的门槛

至少还需要：

1. 对选定的《史记》《汉书》《晋书》等底本完成馆藏、版次、卷页、影像哈希和逐字转录绑定；
2. 分开处理历代距星、宿度和坐标体系，不伪造一个跨时代统一边界；
3. 完成月球、五星、日月食、客星与彗孛的高精度离线位置层及独立锚点测试；
4. 对每条占辞建立适用对象、天象条件、时限、异文、反例、Rule ID 和独立复核；
5. 保证中国古代星占与西方占星的数据、术语和规则完全隔离。

这些条件闭合以前，中国古代星占插件只显示“仅三垣、二十八宿、日月五星身份目录”，不参与裁决。
