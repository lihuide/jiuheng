## 一、先说明“用了古籍”是什么意思

2026-09-27 续轮新增源码输入修复及 `kinqimen` 只读检查：英文 `app` 增加词边界，避免 `happy` 等误分类；固定参考代码的三个所读文件及完整目录观察，发现 LICENSE 缺失并收紧许可状态。《遁甲符应经》影印再次下载失败，未增加已核原页、古籍 Rule ID 或 Windows 发布版本。详情见 [续轮报告](CONTINUATION_2026_09_27_CLASSIFIER_QIMEN.md)。

九衡把古籍使用状态分成三层，不能混称：

1. **机械结构候选**：古籍文字足以支持名称、次序、位置或确定算法，程序可以显示和复算，但不能据此断吉凶。
2. **考证候选**：只取得公共电子转录、OCR、目录或尚未逐页绑定的影印线索，仍须完成底本、页码、字节哈希、异文和独立复核。
3. **正式 Rule ID**：书目、主版本原文、异文、适用条件、反例、逻辑、实现和测试全部通过门禁后，才允许参与推演结论、应期或古法行动建议。

截至 v0.79.0，项目已有较多机械结构和考证候选，但**正式古籍 Rule ID 仍为 0 条，九术完整可裁决仍为 0/9**。因此，下面列出的古籍不等于其全部断法已经进入软件，也不等于软件已经能给出正式古法结论。

- 香港天文台 2023–2026 年历：校验干支日、节气、朔望和现代农历日期锚点。
- NASA 分段 ΔT 模型、NREL SPA 与现代天文公式：校验时间尺度、太阳位置、均时差和节气求解。
- Unicode《易经卦符》标准：校验六十四卦字符编码，不提供断法。
- GeoNames 中国数据：提供离线行政地点中心坐标，不提供传统术数解释。
- `kintaiyi`、`kinastro`、`kinqimen`、`najia`、`iztro` 等开源项目：仅作为实现结构和对拍候选，不能替代古籍证据；开源项目的断语、权重或现代评分不得成为正式规则。
