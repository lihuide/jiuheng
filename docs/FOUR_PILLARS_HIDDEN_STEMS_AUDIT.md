# 四柱地支藏干与十神机械增补（v0.82.0）

## 实现范围

四柱的每个地支展开为歌诀列举的藏干，再复用已有的两天干阴阳、五行方向算法，按该候选的日干标注十神。日柱地支中的藏干也照常按日主计算，不把其中同干项写成“日主”；相同天干的关系为比肩。

| 地支 | 藏干（歌诀列举顺序） |
|---|---|
| 子 | 癸 |
| 丑 | 癸、辛、己 |
| 寅 | 甲、丙、戊 |
| 卯 | 乙 |
| 辰 | 乙、戊、癸 |
| 巳 | 庚、丙、戊 |
| 午 | 丁、己 |
| 未 | 乙、己、丁 |
| 申 | 庚、壬、戊 |
| 酉 | 辛 |
| 戌 | 辛、丁、戊 |
| 亥 | 壬、甲 |

顺序不赋予本气、中气、余气或强弱含义，不计算权重、月内分日司令、透干通根、合化、格局、用神、大运、流年或吉凶。

晚子时按已保存的零点与子初候选分别使用相应的日干、日支和时支，保持并列，不选定其中一套。深圳 1990-05-17 23:50 的固定回归例分别保留壬午与癸未日柱；时支同为子，但子中癸水相对壬日为劫财、相对癸日为比肩。

## 材料与限制

本轮通过[国家图书馆《命理探源》扫描件的检索文字](https://upload.wikimedia.org/wikipedia/commons/5/52/NLC416-07jh011647-5318_%E5%91%BD%E7%90%86%E6%8E%A2%E6%BA%90.pdf)，定位卷上起例“支藏人元五行”、原书页码三三的歌诀；并用[台湾图书馆《渊海子平子平真诠》第一册扫描件的检索文字](https://upload.wikimedia.org/wikipedia/commons/f/fa/NTL-9900014379_%E6%B7%B5%E6%B5%B7%E5%AD%90%E5%B9%B3%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE_v.1.pdf)“又地支藏遁歌”、原书页码三六交叉核对十二支成员。

这些是扫描件的检索文字，存在 OCR 错字；本轮没有完成逐页核图、原文件哈希、版本谱系与独立复核。程序将该成员表明确版本化为机械候选，所有解释与正式规则准入标志保持关闭。完整机器记录见 `data/research/four-pillars-hidden-stems-candidates.json`。

## 保存、兼容与验证

算法版本：`jiuheng.four_pillars.hidden_stems.song_order_day_master_relation.v1`。出生审计 v14、顶层天文快照 v30 新增 `four_pillars_hidden_stems`。旧出生审计 v1–v13 没有此字段时保持缺失，不回填旧记录；新记录若缺失或改变藏干、身份、日界、权重或准入标志，重算比较失败。

验证包含十二支固定表、十个日主与十二支的组合、壬日完整四柱回归向量、晚子时两套日主及日支、数据库保存、变更身份检出与 v13 兼容读取。测试验证机械实现，不代表古籍规则已经独立复核。
