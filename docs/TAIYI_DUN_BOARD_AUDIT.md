# 太乙阴阳遁七十二局机械候选审计

本页记录 v0.42.0 新增的通用七十二局机械框架。调用方必须同时给出一个从一开始的正整数局序和明确的阳遁/阴遁选择；程序只计算太乙、天目、计神、始击、主客算、主客大小将及既有掩/囚/格位置标签。它不会读取现代日期自动选遁或求局，也不采用表中的和不和、击迫关格或胜败断语。

## 固定来源

- 底本标识：Kanripo `KR3g0047`，`BASEEDITION WYG`，《钦定四库全书》本《太乙金镜式经》，题唐王希明撰。
- 固定提交：`e3264da2c9f556225e056abe7eade01903b4543e`。
- 卷一、卷二、卷三固定文本 SHA-256 分别为 `6b13ff06e980439d7a3611f1f10c9efb318513e23f7a9e4c16ed4e8896f162d4`、`44949571367607d1719aa51b5ce174d73078d0c84fe0a81e23b192449c8f5cfd`、`fab52159527f90bf0c74af5f655ae3215e0e7d2efb6a5be5506f12c1671b8257`。
- 卷一 `KR3g0047_WYG_001-11b` 至 `12a` 给出阴遁太乙九宫起逆行、阳遁计神寅起与阴遁计神申起。
- 卷二 `KR3g0047_WYG_002-7b` 至 `8a` 给出计神加和德求始击、二目顺数至太乙求主客算和由算安大小将的通用步骤。
- 卷三 `KR3g0047_WYG_003-9b` 至 `14a` 为阳局七十二行，`14a` 至 `18b` 为阴局七十二行。
- 维基文库卷三和中国哲学书电子化计划的独立公开转录用于交叉发现异文，不能替代尚未取得的四库影印字节。

## 输入与周期

新函数 `taiyi_seventy_two_board_frame_from_count` 的输入只有：

```text
supplied_board_count = 从 1 开始的正整数
dun = Yang 或 Yin，由调用方明确传入
```

局序按一基周期约减：

```text
position_in_72 = (supplied_board_count - 1) mod 72 + 1
```

因此 72 保留为第七十二局，73 回到第一局；零输入直接报错。`u64::MAX` 也会先约减，不发生窄化溢出。

## 太乙、天目和计神

每宫三局、不游中五：

| 遁 | 太乙八宫顺序 |
|---|---|
| 阳遁 | 1、2、3、4、6、7、8、9 |
| 阴遁 | 9、8、7、6、4、3、2、1 |

阴局天目十八位由卷三整表闭合为：

```text
吕申、高丛、太阳、太炅、太炅、太神、大威、天道、大武、
武德、太蔟、阴主、阴德、大义、地主、阳德、和德、和德
```

太炅与和德各重留一局。阴遁计神从申起逆行十二支；阳遁仍从寅起逆行。始击、主客算和大小将继续使用已经单独审计的卷二通用公式。

## 阴局全表对拍发现的冲突

阴局七十二行不是无条件视为绝对正确。逐格对拍发现：

- 客目身份有 3 个冲突单元：第 37、43、44 局；
- 主算或客算有 9 个冲突单元：第 11、15、25、26、27、43、44、46、70 局；
- 其余客目及主客算单元与通用公式闭合。

代表性问题：

- 第 37 局表作客目“大威”、客算 25；按计神加和德通式应为“大武”，而大武到太乙四宫恰得 25，表中身份与本行自己的客算不相容。
- 第 43 局通式得客目“太神”、客算 1，表作“大武”、38；第 44 局通式得“大武”、38，表作“太蔟”、31，显示出相邻行错位的可能。
- 第 25、27、70 局主算分别是公式 31/29/32 与表值 21/39/22，具有单字十位讹写特征，但没有影印定字前不能直接改写原表。

处理原则是双轨保存：研究档案逐项记录“通用公式计算值”和“固定电子文本表值”；程序执行机械公式，测试准确约束冲突集合，绝不为了声称全表一致而修改公式，也绝不把表值悄悄覆盖进计算结果。

## 为什么仍不能从日期起局

显式 `TaiyiDun` 只是算法输入，不是已经解决了阴阳遁选择。以下环节仍未通过门禁：

- 冬至、夏至起算历元及积时口径；
- 现代日期和时刻到局序的完整换算；
- 二至边界和历史历法误差的安全区；
- 卷一夏至加时段“一宫顺行”与随后通法“九宫逆行”的上下文校勘；
- 時計所用直门旋转盘，以及定计大将门盘；v0.43.0 已另按岁计本段“开门加”文字实现太乙、主大将、客大将三个机械子盘，但中五宫仍失败关闭且不解释。

所以普通用户界面没有“当前时间自动排太乙阴局/阳局”的入口。开发者模式只显示这一能力边界。

## 运行与解释门禁

返回对象永久标记：

```text
dun_derived_from_civil_time = false
board_count_derived_from_civil_time = false
complete_board_generated = false
interpretation_eligible = false
signal_eligible = false
rule_eligible = false
```

表内任何“和/不和”“击”“囚”“格”“胜/败”注释都不会进入结论。掩、囚、格只由上一版已经审计的同宫/对宫位置函数重新计算。

## 自动验证

- 阳遁 1–720 局逐字段与既有年计机械框架一致；
- 阴遁 72 行逐项核对太乙、天目、计神、客目、主算和客算；
- 3 个客目、9 个主客算冲突单元必须与研究档案完全一致，增减任何一项都会使测试失败；
- 1/72/73 和最大整数边界均有测试；
- 阴阳两遁均不得自动声称来自民用时间，不得生成完整盘、解释、信号或 Rule ID；
- 研究档案不能进入空的正式规则包。

完整机器档案见 `data/research/taiyi-seventy-two-board-candidates.json`。在影印定字、历元、日期求局和四类复核闭合前，本层只能作为跨平台排盘机械候选。
