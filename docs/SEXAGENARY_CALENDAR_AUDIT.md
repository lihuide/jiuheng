# 干支日与时辰计算审计

## 本页边界

这一层只提供可重复验证的历法标记，不包含八字、奇门、太乙、梅花或其他术式的断法。现代官方历书在这里仅作为日期计算锚点，不会被登记成古籍规则证据，也不能绕过正式 Rule ID 门禁。

当前实现版本：

- 干支日：`jiuheng.sexagenary_day.hko_2024_02_10_anchor.v1`
- 时辰：`jiuheng.shichen.true_solar.two_hour.v1`
- 子时换日状态：`unresolved_tradition_difference_not_rule_eligible`

## 干支日

程序把用户统一输入的 ISO 公历日期按前推格里高利历解释，然后计算该日零点的儒略日数。六十日序号采用：

```text
cycle_index = (Julian Day Number + 49) mod 60
0 = 甲子，59 = 癸亥
```

现代锚点来自香港天文台《香港天文台年历 2024》：2024-02-01 标为乙未日，2024-02-10 标为甲辰日。自动测试同时验证这两个相隔九日的锚点、完整六十循环和 1582 历法切换连续性。

锁定记录会分别保存：

- 北京时间日期在零点换日口径下的干支日；
- 经 SPA 均时差与经度校正后的真太阳时日期，在零点换日口径下的干支日；
- 历法解释、算法版本和原始真太阳时。

## 时辰与条件时柱

十二时辰按两小时区间计算：子时 23:00–00:59，丑时 01:00–02:59，依次至亥时 21:00–22:59。输入采用真太阳时。程序保存距离最近时辰边界的分钟数，并以 5 分钟为当前保守边界带；落入边界带时标记为不安全。

时干采用香港天文台干支说明页列出的日干配子时起干表（即常称“五鼠遁”的机械对应）计算。当前显示的“条件时柱”明确依赖“真太阳时零点换日”这一前提，只用于审计，不参与任何术式规则。

## 尚未裁定

传统术式对晚子时属于当日还是次日存在口径差异。项目尚未完成各术式、各底本的证据拆分，因此不会全局强制采用“23:00 子初换日”或“00:00 换日”。在该差异闭合前：

- 开发者模式同时展示已明确命名的零点口径结果；
- 子时换日状态始终为未决；
- 条件时柱不得驱动正式排盘或断法；
- 将来必须按术式的已放行证据分别选择口径，而不是共享一个未经证明的默认值。

## 来源与验证限制

- 香港天文台《香港天文台年历 2024》：<https://www.hko.gov.hk/tc/gts/astron2024/files/HKO_almanac_2024.pdf>
- 香港天文台“天干地支”：<https://www.hko.gov.hk/sc/gts/time/stemsandbranches.htm>

目前的强验证集中在现代官方锚点、循环不变量、历法切换连续性和时界边界例。它还不等于“公元前 1000 年至未来全范围的独立历书交叉验证”，后者仍是明确未完成项。
