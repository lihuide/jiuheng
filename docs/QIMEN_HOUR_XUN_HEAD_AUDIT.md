# 奇门时旬首、六甲隐仪与地盘落宫机械候选审计

## 本版完成范围

0.29.0 在局数与三奇六仪地盘候选之上新增：

`jiuheng.qimen.hour_xun_head_hidden_instrument_earth_palace.v1`

每套明确命名的时间口径分别保存：

- 由该口径日干和时支形成的时干支；
- 时干支在六十甲子中的十时分组及本旬甲首；
- 甲子、甲戌、甲申、甲午、甲辰、甲寅所隐的戊、己、庚、辛、壬、癸；
- 所隐六仪在同口径地盘中的宫位；
- 距两小时时辰边界的五分钟安全门；
- 算法版本、状态和禁止解释标志。

它只回答“这一时属于哪一旬、旬首所隐之仪在当前地盘哪一宫”，不继续推导值符、值使或任何占断。

## 传本文字与采用边界

《奇门遁甲统宗》卷二公共转录写明旬首从用时干支回溯到本旬甲首，并以乙丑至癸酉归甲子旬、乙亥至癸未归甲戌旬为例。同卷也保存六甲分别隐于六仪，以及“地盘旬首所临之宫”作为后续步骤的基础。

本轮只采用六十甲子本身可验证的十时连续分组，并复用 0.28.0 已审计的六甲隐仪与地盘。公共转录后文涉及值符、值使、九星和八门的内容没有进入程序。国家图书馆扫描件已登记为复核入口，但尚未绑定准确册页与文件哈希，因此本层仍是机械研究候选，不形成 Rule ID。

完整来源与限制保存在：

`data/research/qimen-hour-xun-head-candidates.json`

## 六旬算法与地盘反查

六十时循环以甲子为零位，程序按每十位向下归组：

```text
0–9    甲子旬  隐戊
10–19  甲戌旬  隐己
20–29  甲申旬  隐庚
30–39  甲午旬  隐辛
40–49  甲辰旬  隐壬
50–59  甲寅旬  隐癸
```

得到所隐六仪后，只在同一候选自身的地盘中查找该仪，不允许把北京时间时干支接到真太阳时地盘，或反向混接。自动测试遍历全部六十时，要求每十时恰归一旬；并核对阳一局六旬首依次落一至六宫、阴九局依次落九至四宫。

## 双时制、日界与边界安全

程序并列生成：

- `beijing_civil_clock_and_midnight.v1`
- `true_solar_clock_and_civil_midnight.v1`

两套候选分别使用自己的民用零点日干和自己的钟面时支。`selected_day_convention` 与 `selected_hour_convention` 均保持为空。它们即使数值相同，也不代表已经解决传统时制、真太阳时、子初换日或超神接气等流派问题。

离两小时时辰边界不足五分钟时，`hour_boundary_safe` 为 `false`。只有节气、日界、局数、地盘、时辰边界和旬首落宫全部存在且安全，时旬首候选的 `mechanical_boundaries_safe` 才为 `true`；该标志仍只表示机械输入稳定，不表示允许占断。

处暑因上一层局数异文停用时，程序仍保存时干支、旬首和所隐六仪，方便审计输入，但 `xun_head_palace` 必须为空，机械安全必须为假。程序不会猜一个处暑局数来补齐宫位。

## 明确没有实现

0.29.0 没有实现：

- 北京时间、真太阳时、子初换日等口径的默认选择；
- 超神、接气、置闰、拆补等传承历法选择；
- 值符、值使及其逐时转动；
- 中五寄宫；
- 天盘三奇六仪、九星、八门、八神；
- 格局、用神、吉凶、应期、中间信号或综合裁决。

`interpretation_eligible` 和 `rule_eligible` 恒为 `false`，正式规则种子仍为零条。

## 快照与兼容

顶层天文审计快照从 v19 升级到 v20，奇门审计对象从 v2 升级到 v3。两个日界候选各自新增可空的 `hour_xun_candidate`，顶层新增可空的 `selected_hour_convention`。

v19 历史记录没有时旬首字段，读取时保持为空；v18 记录继续同时缺少地盘和时旬首。程序不会为旧记录补造新候选、重写原始 JSON 或改变哈希。开发者重算对 v20 做完整比较，对 v19 只比较当时已有的局数与地盘字段，对 v18 只比较局数字段。
