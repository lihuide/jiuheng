# 九衡 v0.82.0 Windows 交付

日期：2026-11-12。范围：六爻、四柱和紫微机械排盘记录试用版。

## 本次完善

- 四柱新增十二地支藏干及相对日主的十神机械身份；普通页面按年、月、日、时四列显示干支、阴阳五行、明干十神、藏干十神。
- 晚子时分别显示两套日界候选，按各自的日主与地支计算藏干身份；不静默合并或替用户选择。
- 紫微新增普通界面的十二宫图。将已有的宫干、命宫、身宫、五行局、十四主星和四辅星集中到对应宫位；农历年/立春年和北京时间/真太阳时形成四套并列候选。
- 含出生资料的占问锁定后直接打开机械盘，无需先完成六次铜钱起法。历史记录和侧边栏均可进入。
- 两项机械盘支持复制全部候选和导出离线 HTML；可用浏览器打印。每次导出生成新文件，原有六爻报告与续接功能保留。
- 出生审计升级为 v14、顶层快照为 v30；重开报告先校验保存内容并重算核对，再显示原始保存字段。旧记录未保存的藏干或星位明确标记，不改写原记录。

## 验证与交付

完整工作区 419 项 Rust 测试通过：核心 265 项、核心参考 6 项、存储 86 项、研究门禁 45 项、桌面 17 项；版本号更新后，最终桌面 17 项再通过。20 项 Python 测试通过。新增验证覆盖十二支藏干、日主十神关系、晚子时双候选、保存与旧版本兼容、星位归宫、历史重开、出生资料锁定后直达机械盘，以及导出内容转义与不覆盖旧文件。

最终格式检查、严格静态检查和 release 构建通过。普通界面已通过 egui 渲染和流程测试；离线 HTML 使用实际浏览器检查了四柱表格、宫位布局和中文显示。浏览器样本使用同一报告实现，生成于产品版本号更新前，页脚仍为 v0.81.0；最终构建及安装包版本已核对为 v0.82.0。未把这些验证表述为全部原生按钮的人工实机验收。
