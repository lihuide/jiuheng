## 最近实际新增了什么

### 太乙开源实现比较

对用户提供的 `kintaiyi` 固定版本，只解析公开主客算常量表，不执行第三方 Python 模块。完成阴阳遁 144 局、288 个数值比较，其中 140 局两值完全一致，4 局各有一处差异：阳 44 局主算、阴 10 局客算、阴 39 局主算、阴 61 局客算。

参考值、来源文件哈希、MIT 许可和精确差异均已保存。四处差异没有自动改成开源项目的值，仍要回到古籍影印核定。开源代码只能帮助实现和比较，不能替代古籍证据，也没有据此创建正式 Rule ID。

### 太乙传统年标签到积年

Rust 核心新增显式传本历元候选：按《太乙金镜式经》卷一电子转录中开元十二年甲子积 1,937,281 算的锚，从明确给定的传统年标签计算积年并接入既有年计机械盘。全部 4,000 个支持标签均已测试，覆盖公元前跨零、范围边界、六十循环及确定性序列化。

这一入口不接收现代日期，不选择冬至、正月或立春年界，不启用存在年号与干支矛盾的另一历元；影印核验、解释、信号、应期与规则准入均保持关闭。Windows 界面尚未调用它。

### 本轮交付工具

新增 `scripts/package-source.py`，使用标准库直接打包，不先复制整个源码目录，不重复占用临时目录空间。包内保存全部文件的长度及 SHA-256；核验时逐字节比较当前源码与压缩包，拒绝缺文件、多文件、重复条目、路径越界、缓存混入、版本不符及内容被修改。已有源码包拒绝覆盖，失败不删除现场。

新增 10 项交付回归测试，配合此前 5 项参考提取安全测试，15 项 Python 测试全部通过。该工具改善源码交付，并不代表术式断法已经完成。

## 已实现的共用功能

- Rust 核心、SQLite 存储和 Windows 中文界面分离；运行不使用登录、服务器、联网 API 或 AI。
- 固定问题类别与子类、纯关键词和同义词映射；混合主题提示歧义，不擅自选类别。
- 占问参数校验、问题锁定、北京时间和历史时间输入；必要出生参数不足时跳过相关术式。
- 离线大陆省市区县地点及 34,535 条乡镇街道名称；街道坐标目前使用匹配区县中心近似，界面明示精度。
- 事件指纹、不二占拦截、情况变化说明和 EVENT_REVISION 链；不添加任意冷却期。
- SQLite 本地记录、随机材料保存、版本化审计快照与确定性历史重放。
- 六爻三币六次和蓍草十八变交互；梅花时间起卦的机械基础。
- 历法、真太阳时、节气与朔望候选，以及五星近似几何向量研究层。
- 九术适用性检查、同权融合框架、应期区间和行动建议数据链；没有正式规则时停止裁决，不编造结果。
- 开发者模式展示机械盘、历法天文、规则缺项、古籍来源档案、影印字节核验与重放检查。
- 健康类别及关键词映射进入的健康问题均保留医学安全提示。
