# 六爻传世纳甲干支机械层审计

## 本版完成范围

`jiuheng.liuyao.received_najia_stem_branch.v1` 在六次三币转录通过原版本重放、六位卦象通过八宫唯一映射之后，为本卦六爻派生：

- 下三爻按下卦使用内卦表；
- 上三爻按上卦使用外卦表；
- 每爻的纳甲天干、地支与地支五行；
- 已有世爻、应爻标记与对应爻位绑定。

九衡一律按初爻到上爻存储。传世八纯卦表共 48 个位置进入自动测试；任意上下卦组合均由对应下卦内表和上卦外表构成，覆盖 64 卦、384 爻。

## 表方向与机械规则

乾内甲外壬，坤内乙外癸；震庚、巽辛、坎戊、离己、艮丙、兑丁内外同干。地支按八卦各自内外三爻表固定，不由日期、问题类型或随机点击改变。

公开的《增删卜易》电子表按上爻到初爻展示，九衡研究档案明确逆序为初爻到上爻；方向转换被机器测试固定，禁止依靠界面顺序猜测。

## 证据边界

本轮交叉使用《京氏易传》公共电子转录、《增删卜易》八纯卦纳甲图电子表，以及惠栋《易汉学》卷四所录八卦六位图。《易汉学》本身把该图层次标为出《火珠林》，这正是九衡不把后世完整表无条件署为无争议“汉京房原表”的理由。

三种材料尚未逐页下载为本地不可变影像、计算 SHA-256 并完成异文校勘，所以这里只建立“传世纳甲干支机械候选”，不生成正式 Rule ID。机器可读表、来源限制与禁用项保存在 `data/research/liuyao-najia-stem-branch-candidates.json`。

## 历史复现

纳甲表不新增数据库字段，也不改写旧记录。历史一键重放先验证六次随机材料、主种子、转录哈希和本卦位图，再按固定算法版本派生八宫、世应和纳甲干支。任何底层材料被篡改时，派生层不会运行。

普通起法页只提示纳甲机械表已生成；开发者模式和历史重放可逐爻查看上下卦、纳甲干支五行与世应标记。

## 明确未实现

以下全部保持失败关闭：

- 六亲；
- 六神与伏神；
- 用神、月建、日辰、旬空、旺衰；
- 动爻关系、进退化、应期；
- 吉凶、成败、中间信号、结论和行动建议；
- 正式 Rule ID 与综合裁决参与资格。

地支五行只是每爻的结构元数据，不等于旺衰或六亲，也不得单独转化为吉凶分数。

## 自动护栏

- 八纯卦 48 个干支五行位置逐项对表。
- 穷举 64 卦，验证下卦只取内表、上卦只取外表。
- 穷举 384 爻并验证每卦恰有一个世爻、一个应爻。
- 研究 JSON 与 Rust 输出逐项对拍。
- 历史重放证明必须同时包含八宫审计和纳甲审计。
- 正式规则种子必须继续为空，六亲、六神、解释、信号和规则资格必须为否。
