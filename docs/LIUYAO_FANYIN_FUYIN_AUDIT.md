# 六爻反吟、伏吟原始结构审计

## 本版完成范围

`jiuheng.liuyao.received_fanyin_fuyin_raw_structures.v1` 不直接给整卦贴“反吟”或“伏吟”标签，而是把传本中可能参与这些术语的机械事实拆成三层保存：

1. 内卦或外卦的本卦八卦与变卦八卦是否属于方位对冲对。
2. 内卦或外卦三个同位纳甲地支是否全部相冲，或是否全部复现不变。
3. 每条实际动爻的本支与同位变支是否同支或相冲。

范围候选必须至少包含一条实际动爻。静卦虽然本卦和变卦结构相同，也不会被虚构成伏吟。

## 四组八卦方位对冲

| 第一卦 | 对卦 |
|---|---|
| 乾 | 巽 |
| 坎 | 离 |
| 震 | 兑 |
| 坤 | 艮 |

程序把四组保存为对称伙伴关系：乾→巽与巽→乾都能命中，但任一卦不会与自身命中。

这张表只描述传本所用的方位对冲目录，不等于三个纳甲爻支都会相冲，也不等于已经发生任何吉凶效力。

## 同位支的两种原始关系

### 全部对冲

内卦使用初、二、三爻，外卦使用四、五、上爻。只有一个范围内三个“本支→变支”都属于六冲对，才保存“三支同位全冲候选”。单独一条动爻相冲只保存在逐爻观察中，不自动提升为整个范围。

### 全部复现

只有一个范围内三个同位地支全部相等，且该范围至少有一条实际动爻，才保存“三支同位复现候选”。这能排除无动爻范围天然的本变相同。

## 为什么不直接发布整卦反吟、伏吟

《卜筮正宗》影印/OCR 及《增删卜易》《易林补遗》《易冒》的公开转录都能支持“八卦方位对冲”“变支相冲”“变支复现”这些基础结构，但在以下方面仍须校勘：

- 卦之反吟与爻之反吟的术语边界。
- 仅内卦、仅外卦及内外俱见时如何组合命名。
- 单条动爻同支/对支能否独立使用相同术语。
- 八卦对冲与三条纳甲支全冲同时出现或分别出现时如何分层。

因此本版只显示“卦向对冲”“三支同位全冲”“三支同位复现”“动爻同支/对支”等中性事实。整卦反吟、整卦伏吟两个发布开关固定为关闭。

## 自动验证

- 四组八卦伙伴必须双向对称，八卦全部覆盖且不能指向自身。
- 六冲支仍由十二支环相隔六位的既有函数计算。
- 穷举 `4^6 = 4,096` 种六七八九爻型组合。
- 每种组合分别生成内卦、外卦两个范围观察。
- 实际动爻逐条观察合计 12,288 条；静爻不生成逐爻记录。
- 每个范围重新核对三条本支与变支，不从显示标签反推结果。
- 无实际动爻的范围，三个候选标记必须全部为否。
- 新起卦、历史页和一键重放调用同一个核心函数。
- 正式规则种子仍为空，解释和裁决开关保持关闭。

## 古籍候选

- 《卜筮正宗全书》卷三、卷四哈佛燕京藏本影印：当前最直接的“反吟卦定例第十一”“伏吟卦定例第十二”影印/OCR 线索。
- 《增删卜易》反吟伏吟段：区分卦反吟、爻反吟及内外范围的电子转录候选。
- 《易林补遗》卷五：卦犯、爻犯、同支与对冲示例的交叉候选。
- 《易冒》卷二反伏章：明确警示卦反、爻反及真假轻重不能混为一层。

哈佛影印尚未下载到项目内并绑定准确图页、字节和 SHA-256；其他来源主要是公共电子转录或 OCR。因此这些资料目前只能支持研究机械层，不能生成正式 Rule ID。

研究档案：`data/research/liuyao-fanyin-fuyin-candidates.json`。
