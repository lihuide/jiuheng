# 奇门阴阳遁、三元与局数机械候选审计

## 本版完成范围

0.27.0 新增算法：

`jiuheng.qimen.received_solar_term_three_yuan_ju_candidate.v1`

这一层只计算并保存：

- 冬至至芒种十二节气为阳遁，夏至至大雪十二节气为阴遁；
- 六十甲子日每五日分一组，以组首甲日或己日为符头；
- 符头支为子午卯酉时取上元，寅申巳亥取中元，辰戌丑未取下元；
- 依据当前节气和上中下元取得一个局数机械候选；
- 北京时间民用零点换日、真太阳时民用零点换日两套候选及各自的五分钟日界安全状态；
- 节气边界安全状态、算法版本、证据冲突和全部失败关闭原因。

它不是完整奇门盘，也不能生成占断。

## 文本线索与异文处理

《奇门遁甲统宗》公共转录保存“五日换一元”和阴阳二遁三元局数歌诀。《古今图书集成》相关影像挂接页明确写出五日一候、甲己为符头，以及三组符头地支对应上中下元，并解释“冬至一七四”为上元一局、中元七局、下元四局。

本轮核到一个不能忽略的冲突：

- 《奇门遁甲统宗》和《奇门遁甲秘笈大全》公共转录的处暑条为“一四七”；
- 《古今图书集成》影像挂接页当前文本显示“一七四”，且该页标记为未校对；
- 国家图书馆藏《奇门遁甲统宗》扫描件已经登记为复核入口，但尚未完成准确册页绑定和逐字校勘。

因此程序不以多数转录代替版本校勘。处暑的 `received_bureau_numbers` 固定返回空值，`table_entry_evidence_conflict` 固定为 `true`，候选不能通过机械安全门。其余二十三个节气按当前一致的传本表作为审计候选。

完整来源、表值和限制保存在：

`data/research/qimen-solar-term-three-yuan-ju-candidates.json`

## 局数表的程序表达

数组顺序固定为 `[上元, 中元, 下元]`。程序对相同表项合并实现，但测试逐个覆盖两个阴阳遁半区的锚点。处暑保留空值，不猜测补齐。

```text
阳遁：冬至/惊蛰 174；小寒 285；大寒/春分 396；
      立春 852；雨水 963；清明/立夏 417；
      谷雨/小满 528；芒种 639。

阴遁：夏至/白露 936；小暑 825；大暑/秋分 714；
      立秋 258；处暑 停用；寒露/立冬 693；
      霜降/小雪 582；大雪 471。
```

## 并列口径与边界门

输入时刻先由既有天文层求得当前节气区间、北京时间干支日和真太阳时干支日。两种日界口径分别计算符头、三元和局数，不自动选一套：

- `beijing_civil_midnight.v1`
- `true_solar_civil_midnight.v1`

离任一民用零点不超过五分钟时，该口径的 `day_boundary_safe` 为 `false`。离节气交接不超过“天文合成不确定度 + 五分钟”时，`solar_term_boundary_safe` 为 `false`。只有日界、节气边界和局数表项都安全时，单个候选的 `mechanical_boundaries_safe` 才为 `true`。

即使两个口径恰好产生相同结果，`selected_day_convention` 仍为 `null`。程序也不据此默认选择超神、接气、置闰、拆补等历法传承。

## 明确没有实现

0.27.0 没有实现：

- 超神、接气、置闰、拆补等口径选择；
- 地盘、天盘、九宫、九星、八门、八神、值符和值使排布；
- 阴盘、飞盘等其他体系的自动混用；
- 格局、用神、吉凶、应期或任何问题类型断法；
- Rule ID、中间信号、术式分数或综合裁决。

`selected_day_convention`、`transmission_calendar_adjustment_selected` 恒为空，`rule_eligible` 恒为 `false`。正式规则种子仍为零条。

## 快照与兼容

锁定占问时，两个日界候选连同节气区间和失败关闭状态写入不可变天文审计快照。顶层快照从 v17 升级到 v18。v1–v17 历史快照缺少奇门字段时仍按原始 JSON 字节读取；程序不会补造候选、改变旧哈希或静默重算。

开发者模式会显示两套候选，并在重算校验中将当前 v1 算法结果与 v18 固化值逐项比较。处暑停用状态、日界口径、符头、三元、局数、边界安全或阻断原因变化都会导致“不一致”。

## 进入完整排盘与正式规则前的门槛

至少还需要：

1. 把局数歌诀、符头三元和处暑异文逐条绑定到权威影印底本的具体卷页、影像哈希与校勘记录；
2. 完成超神、接气、置闰、拆补等口径的版本谱系，明确第一版采用的主流传承及适用边界；
3. 确定日界口径，或者证明在何种条件下可安全合并；
4. 对九宫盘、九星、八门、八神和值符值使逐层建立机械不变量和独立锚点；
5. 对每条断法建立适用问题、条件、结果、应期、异文、反例、Rule ID 和独立复核。

这些条件闭合以前，奇门插件只显示“局数机械候选”，不参与裁决。
