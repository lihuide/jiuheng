# 六爻伏神机械候选审计

## 本版完成范围

`jiuheng.liuyao.received_palace_pure_hexagram_hidden_spirits.v1` 检查本卦六爻已经显现的六亲。若父母、兄弟、子孙、妻财或官鬼中的某类完全没有出现，就到本卦所属八宫的本宫首卦中寻找该六亲，并按相同爻位放在本卦飞神之下，形成伏神结构候选。

每个候选同时保存：爻位、本宫卦纳甲干支、伏神六亲，以及该位当前本卦的飞神干支与六亲。

## 机械规则与锚点

- 来源固定为当前卦所属宫的本宫纯卦，不跨宫借取。
- 只有某一六亲在本卦六爻完全缺失时才寻找。
- 本宫卦第几爻的该六亲，就伏在本卦同一爻位之下。
- 本宫纯卦六亲齐全，不生成伏神候选。

乾宫传本锚点已经进入自动测试：姤缺财，借乾宫二爻甲寅木；遯同时缺子孙与妻财，借初爻甲子水和二爻甲寅木；观缺子孙与兄弟，借初爻甲子水和五爻壬申金；剥缺兄弟，借五爻壬申金。

## 证据边界

《卜筮正宗》电子转录明确记载本宫下七卦缺六亲时以八宫首卦为伏，并列出乾宫姤、遯、否、晋、观、剥的借取锚点。《卜筮全书》电子转录说明卦上为飞、本宫同位为伏；《易隐》传本卦例提供伏神、本卦、变卦的同位展示交叉核验。

当前仍未把相应影印页固定为本地不可变字节并计算 SHA-256，京房、火珠林及明清传本之间的版本谱系也没有闭合。因此本版只实现缺失六亲的同位结构候选，不生成正式 Rule ID。

## 明确排除

- 不判断飞神是否生、克、冲开或压住伏神。
- 不判断伏神是否得日月、是否空破、是否能够出现。
- 不把伏神自动选为用神。
- 不采用“用爻已出现仍强制察伏神”等有分歧扩展。
- 不生成旺衰、动变、应期、中间信号、结论或行动建议。

## 自动护栏

- 乾宫姤、遯、观、剥的伏神爻位、干支和六亲逐项对表。
- 穷举 64 卦，验证显现与缺失六亲集合互斥且合计正好五类。
- 每个缺失六亲必须能在所属宫本宫卦中找到同位候选。
- 伏神与飞神爻位必须完全一致。
- 研究 JSON 与 Rust 锚点逐项对拍，正式规则种子继续为空。
