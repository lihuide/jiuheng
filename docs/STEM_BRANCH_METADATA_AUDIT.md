# 干支阴阳五行结构元数据审计

## 本版范围

0.21.0 为四柱机械候选增加干支的阴阳与五行结构标记。算法版本为 `jiuheng.stem_branch.yinyang_five_elements.huainanzi_wuxingdayi_leijingtuyi.v1`，状态为 `structural_metadata_only_not_strength_or_fortune_rule.v1`。

这些字段只是固定对应表：每柱分别保存天干阴阳、天干五行、地支阴阳和地支五行。这个元数据模块本身没有统计五行数量，没有计算旺衰、藏干、格局或吉凶，也不会把这些字段转成中间信号。v0.71.0 的独立派生层会据此计算三个非日主明干的十神机械身份，但仍不解释强弱或吉凶。

## 文献边界

- 《淮南子·天文训》按东、南、中、西、北列甲乙为木、丙丁为火、戊己为土、庚辛为金、壬癸为水，是天干五行对应的早期核心依据。
- 隋萧吉《五行大义》卷二列甲、乙等十干的五行，并列寅卯木、巳午火、申酉金、亥子水、辰未戌丑土；同卷又明列甲丙戊庚壬为阳、乙丁己辛癸为阴。
- 明张介宾《类经图翼》提供完整、逐项的干支阴阳五行表，用作实现表的可读交叉核对；它不覆盖或提高早期材料的优先级。

本版录入的是三处材料没有冲突的结构对应。文献中的生克、德刑、旺相和其他解释段落没有随表一起进入程序。

## 固定对应

- 天干：甲阳木、乙阴木；丙阳火、丁阴火；戊阳土、己阴土；庚阳金、辛阴金；壬阳水、癸阴水。
- 地支：子阳水、亥阴水；寅阳木、卯阴木；巳阴火、午阳火；申阳金、酉阴金；辰戌阳土、丑未阴土。

实现采用穷举匹配，不依赖字符串、区域设置或运行时数据库。十干和十二支全部有逐项自动测试；`甲子` 的固定显示回归向量为 `甲（阳木）子（阳水）`。

## 与规则门禁的关系

结构元数据自 `BirthTimeAuditSnapshot v4` 起固化并参与重算一致性校验；v9 另存明干十神机械身份。两者都不创建 Rule ID、不形成规则命中、不改变四柱插件的“仅排盘”状态。任何解释规则仍必须单独完成底本、原文定位、异文、逻辑、实现和边界测试审查。
