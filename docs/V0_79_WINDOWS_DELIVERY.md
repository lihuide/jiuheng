# 九衡 v0.79.0 Windows 交付

日期：2026-10-11。

| 文件 | 用途 |
|---|---|
| `Jiuheng-Setup-x64-0.79.0.exe` | Windows 10/11 x64 安装包 |
| `Jiuheng-Portable-x64-0.79.0.exe` | 不需安装的单文件便携版 |
| `Jiuheng-Source-NoComments-0.79.0.zip` | 完整源码、文档、研究材料和原页；Rust、Python、TOML 代码注释及 Python 文档字符串在打包时移除 |
| `SHA256SUMS-0.79.0.txt` | 前三个文件的 SHA-256 校验值 |

本版将六爻降雨候选的研究检查增量编入 Windows 程序：保守排除可见爻与月建对支、旬中未配支，以及父母爻与其他可见爻、月建或日辰有原始六合配对的盘。开发者模式可以查看具体爻位。这些只是原始结构，不是月破、空亡或合住已生效的断法；软件仍不输出降雨预测。正式 Rule ID 为 0，九术完整可裁决为 0/9。

无注释源码包保持全部必要源文件的相对路径。它保留用户文档、古籍影印、许可证、第三方声明以及 `SOURCE-MANIFEST.json`；清单记录打包后各文件的字节数和 SHA-256，也记录原始工作区文件的 SHA-256。删除的是代码注释，不删程序、测试、数据或引用证据。打包器及测试位于 `scripts/package-source.py` 和 `scripts/tests/test_source_package.py`。

验证：完整工作区 393 项 Rust 测试、20 项 Python 测试、格式检查及严格静态检查通过。正式 x64 程序与安装包由固定 Rust/MSVC 工具链构建；安装包已在隔离目录完成静默安装、启动、SQLite 建库和静默卸载。无注释源码包的独立编译、逐文件校验与交付文件校验在成包后完成。

安装包未附商业代码签名，Windows 可能提示未知发布者。本机验证不等于所有 Windows 10/11 设备的兼容性验收。
