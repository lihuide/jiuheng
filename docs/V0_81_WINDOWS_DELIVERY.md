# 九衡 v0.81.0 Windows 交付

日期：2026-11-12。版本定位：六爻排盘记录试用版。

## 本次完善

- 六爻逐次保存：每次操作确认写入后才显示新爻。保存会话初始材料、原有爻及追加操作，重新打开程序后可从历史记录继续。
- 历史列表显示“已保存 N/6 · 可继续”，详情与未完成报告提供“继续六爻起法”。继续使用原问题、原占问时间、地点和历法快照，不新增占问，不替换已保存的爻。
- 保存失败时暂停下一次起法，保留当前操作供重试。重复提交相同操作不会重复生成爻；其他窗口已经更新时拒绝覆盖，可重新读取已保存进度。
- 第六爻和最终排盘在同一数据库事务内提交。中途失败保留此前五爻，重试后完成原次操作；校验失败不重置原始记录。
- 自动升级旧数据库，保留旧锁题、完整六爻、已完成蓍草和历法快照。恢复六爻时，已完成蓍草仍保持完成状态和原程序约定。
- v0.80.0 的六爻报告、全部历史搜索、分页、文字复制和离线网页导出继续保留。
