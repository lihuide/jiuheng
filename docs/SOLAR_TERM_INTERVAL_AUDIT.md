# 双向节气区间审计

## 用途与边界

本模块只回答三个可验证的天文问题：给定 TT 时刻之前最近的节气是什么、之后最近的节气是什么、该时刻是否离节气边界足够远。它不自行决定八字月柱、立春换年、奇门定局或任何断法。

算法版本：

- 相邻节气：`jiuheng.solar_term_interval.bidirectional_bisection.v1`
- 节/中气分层：`jiuheng.solar_term_class_interval.jie_zhongqi.v1`

## 计算过程

1. 使用同一版本的 NREL SPA 太阳视黄经重实现计算当前黄经。
2. 以春分 0° 起，每 15° 对应一个节气，确定前后两个目标黄经。
3. 分别向前、向后建立不超过 60 日的包围区间。
4. 对两个黄经穿越点使用二分法求解，终止包围宽度不超过 0.1 秒。
5. 将求解器半包围宽度与太阳位置保守角误差折算的时间误差相加，分别保存为前后边界的不确定度。
6. 当前时刻与两个边界的距离都必须大于“该边界合成不确定度 + 额外 300 秒”，才标记为边界安全。

锁定占问会在 v4 哈希快照中保存前后节气、JD(TT)、不确定度、迭代次数、已过/剩余秒数、安全边距、最终安全状态和算法版本。v1–v3 快照继续按原 JSON 读取，不补字段、不静默重算。

## 节与中气分层

香港天文台列出的十二中气从春分、谷雨、小满依次至雨水；穿插其间的十二节从清明、立夏、芒种依次至惊蛰。程序按该完整序列把 24 个黄经点分为 `Jie` 与 `Zhongqi`，然后各自求解前后边界。这会同时产生：

- 最近节 → 下一节；
- 最近中气 → 下一中气；
- 两套区间各自的误差、已过/剩余时间和边界安全状态。

v5 快照保存两套完整区间。它们仅为下游历法提供数据：节区间不自动成为月柱，中气区间也不自动生成农历月份或闰月。

## 自动验证

- 线性太阳测试覆盖普通区间与 360°/0° 黄经环绕。
- 精确落在节气穿越点时必须判为不安全。
- NaN 或负安全边距必须返回错误。
- 香港天文台《年历 2024》现代锚点：大寒 2024-01-20 22:07、立春 2024-02-04 16:27、雨水 2024-02-19 12:13、惊蛰 2024-03-05 10:23（UTC+8）。SPA 求解结果必须全部落在年历分钟值的 90 秒容差内，并分别正确识别“立春 → 惊蛰”的节区间和“大寒 → 雨水”的中气区间。

香港天文台说明，其节气资料采用香港时间（UTC+8），天文数据依据英国皇家航海历书局及美国海军天文气象台资料计算：

- <https://www.hko.gov.hk/sc/gts/astronomy/Solar_Term.htm>
- <https://www.hko.gov.hk/sc/gts/time/24solarterms.htm>
- <https://www.hko.gov.hk/tc/gts/astron2024/files/HKO_almanac_2024.pdf>

太阳位置方法参考：I. Reda, A. Andreas, *Solar Position Algorithm for Solar Radiation Applications*, NREL/TP-560-34302。
