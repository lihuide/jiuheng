# 九衡排盘记录试用版使用说明

适用版本：v0.84.0。Windows 10/11 x64，完全离线。

1. 打开安装版或便携版，在“新建占问”填写清晰问题、主体、对象、目标事件和地点，核对时间后锁定。
2. 在“六爻 · 三枚铜钱”按住起法按钮再松开，连续完成六次。六爻从初爻向上记录，每次显示结果前自动保存，同一问题不能重新摇卦。中途退出后，在“永久记录”选中原问题，点击“继续六爻起法”，接着完成剩余次数。
3. 点击“查看完整六爻排盘报告”。本卦、变卦、世应、六亲、纳甲和六神集中展示；动爻用不同颜色显示。图表从上爻排到初爻。
4. 点击“复制文字记录”可粘贴到自己的笔记；“导出离线网页报告”生成一个 HTML 文件。点击“打开报告所在文件夹”，双击文件即可用浏览器离线阅读，或使用浏览器打印功能保存为 PDF。
5. 关闭并重新打开程序后，进入“永久记录”，按问题、主体、地点、锁定日期或记录编号搜索。搜索覆盖全部记录，每页最多 50 条。选中记录后点击“打开六爻排盘报告 / 导出”。

每次打开报告都会重新读取本地保存的起法材料并核对结果；校验失败时不生成报告。未完成六次的记录会明确显示“待完成”。历史记录不会因为打开报告而重新摇卦或修改原始问题。

本版提供排盘与记录。结构标签与动爻变化说明不包含旺衰、用神、吉凶、应期、降雨预测或古法行动建议。蓍草与梅花现有研究入口继续保留。

导出目录为本地数据库旁的 `exports` 文件夹，界面显示完整保存路径；每次导出生成新文件，不覆盖旧报告。报告包含占问内容、时间和地点。导出文件便于阅读，不能替代原始数据库备份。

安装版和便携版默认使用同一 Windows 用户的本地数据目录；便携程序免安装，但数据默认不跟随 EXE 搬动。若本地目录不可写，程序会明确提示临时内存模式，此时退出后不保留记录，网页导出按钮停用。

## 中途退出、保存失败与升级

- 历史列表显示“六爻已保存 N/6 · 可继续”。继续时仍使用原占问时间、地点和问题，不需要重新锁题，也不替换已有的爻。
- 保存失败时，界面暂停下一次起法。点击“重试保存本次操作”会重试相同材料；如果同一记录在其他窗口已经更新，点击“重新读取已保存进度”，按数据库中已确认的结果继续。
- 完成第六次后，最后一爻和完整排盘一起保存；未完成记录只显示保存次数，不生成完整排盘。
- v0.81.0 自动升级现有数据库，保留旧版本的锁题、完整排盘和历法快照。旧版本从未保存到磁盘的中途操作无法找回；旧“仅锁题”记录可从第一爻开始。
- 本次中途恢复适用于“六爻 · 三枚铜钱”。蓍草研究入口的中间步骤尚未加入退出续接。

## 四柱与紫微机械盘（v0.82.0）

1. 在“新建占问”选择“长期命运”，填写问题及主体等资料，勾选提供完整出生参数，输入出生时间、性别与出生地点，核对后锁定。出生时间输入采用北京时间；界面另列真太阳时换算和地点精度。
2. 锁定后直接进入“四柱 / 紫微机械盘”，无需先完成六次铜钱起法。侧边栏可随时返回这一页。
3. “四柱 · 藏干与十神”显示年、月、日、时柱、阴阳五行、明干十神和藏干十神。晚子时两套日界候选并列；藏干列举顺序不表示力量排序。
4. “紫微 · 十二宫”显示十二宫、宫干、命宫、身宫、五行局、十四主星与文昌、文曲、左辅、右弼。农历年/立春年和北京时间/真太阳时形成四套并列候选，程序未替你选定一套。
5. “复制全部机械盘”及“导出机械盘网页”包含两项术法的全部已保存候选，网页可离线查看或通过浏览器打印。导出目录为数据库旁的 `exports`；每次生成新文件。报告包含出生时间和地点。
6. 从“永久记录”选中带出生资料的记录，点击“打开四柱 / 紫微机械盘”即可重新核对并查看。旧记录若没有藏干或部分星位，会显示“旧记录未保存”，不会覆盖旧数据。

这两项当前用于核对机械排布。四柱强弱、格局、用神、大运、流年，以及紫微四化、其余辅煞、大限和吉凶应期尚未完成。临时内存模式关闭后不能恢复，文件导出入口停用。

## 梅花与奇门机械盘（v0.83.0）

1. 新建并锁定占问后，点击侧边栏“梅花 / 奇门机械盘”，或起法页的“查看梅花 / 奇门机械盘 · 复制与导出”。这里使用原占问时间和占问地点，无需出生资料，也无需完成六次铜钱起法。
2. “梅花 · 时间卦象”分别显示北京时间与真太阳时的取数过程、本卦、变卦和动爻。爻从上爻排到初爻，动爻用不同颜色标记。下方的中爻结构标为派生观察，尚未选定正式互卦口径。
3. “奇门 · 九宫地盘”分别显示两种时间口径的节气、阴阳遁、三元、局数、符头、时旬首及三奇六仪地盘。图中“本旬值符身份”和“本旬值使取门宫”不是当前时刻移动后的星门落宫；完整天盘、逐时星门与八神仍未完成。
4. 闰月尚未确定梅花取数口径时不显示卦象；奇门局数有传本文字冲突时不显示地盘。边界时间、两套结果不同、旧记录缺字段均有提示，不自动替你选定口径。
5. “复制梅花与奇门全部候选”及“导出梅花与奇门网页”包含两项的全部保存候选。网页可离线查看或打印，保存在数据库旁的 `exports`，每次生成新文件。临时内存模式下文件导出停用。
6. 退出后从“永久记录”选中原问题，点击“打开梅花 / 奇门机械盘”即可重开。读取时核对快照内容，并按原占问时间和地点复算梅花/奇门字段；不把当前系统时间代入旧盘，不改变六爻保存进度。

两项都只展示机械结构，不提供体用旺衰、吉凶、应期或行动判断。导出文件包含原问题、时间和地点，不能替代数据库备份。

## 太乙机械盘（v0.84.0）

1. 锁定问题后点击侧栏“太乙机械盘”，或从永久记录选中问题，点击“打开太乙机械盘 / 已存候选”。无需出生资料或六爻起法。
2. 选择输入方式。“已知积年”输入正整数；“传统年标签”须明确勾选 724 年积年 1,937,281 的传本假设，范围 -999 至 3000，0 表示公元前 1 年；“阴阳遁局序”须明确选择阴遁或阳遁，再输入正整数局序。没有默认代入电脑年份或自动选遁。
3. 点击“计算并保存候选”。太乙九宫显示太乙、主客大将与参将；十六神定位显示天目与始击。太乙采用自己的宫号，上南下北、左东右西。
4. 年计另列开门分别加太乙、主大将、客大将的三张独立八门盘。某将位在中五时，该将门盘停止生成，其余可用门盘保留。阴阳七十二局不拼接年计门盘。
5. 已存候选下拉框可切换。相同问题、相同参数只存一份；不同参数新增候选，不替换原盘，也不改变原占问时间或六爻起法。
6. 点击“复制当前太乙候选”或“导出太乙网页”。导出保存到数据库旁的 exports，每次生成新文件，可离线阅读或打印。历史重开先核对保存内容，再按原参数复算；失败时停止展示。

数据库自动升级至 schema 14，新增太乙候选表，旧占问及历法快照不回填。实际日期到传统年界和阴阳遁尚未确定；年标签锚点及部分阴遁主客算仍有待复核材料。这里提供明确参数的机械候选，不是完整太乙占断。临时内存模式关闭后记录丢失，文件导出停用。
