# 出生参数、真太阳时与命理术式适用性审计

## 范围

长期命理类别可以离线填写：

- 性别；
- 出生年月日时，统一按北京时间 UTC+8；
- 中国大陆离线出生地点及其行政中心近似经纬度。

这些参数建立可复现的数据与历法基础。0.21.0 已生成带干支阴阳五行结构标记的四柱八字机械排盘候选，0.71.0 再加入年干、月干、时干相对日主的十神机械身份；0.24.0 新增紫微命宫、身宫与十二宫机械候选；0.25.0 再加入宫干、纳音和五行局候选；0.48.0 增加七政与四余十一曜身份目录。它们都不含断法，七政四余的四余天文角色、位置、宿度、十二宫和命盘仍未完成。

## 参数校验

校验器版本为 `jiuheng.question_parameters.cn_bjt.v1`。桌面层和 SQLite 写入层都会执行同一套校验，防止绕过界面写入无效记录：

- 问题原文和目标事件不得为空；
- 占问地点、出生地点第一版必须来自中国大陆范围的离线数据；
- 省、市字段不得为空，经纬度必须是合法有限数值；
- 占问、锁定和出生时间必须以 UTC+8 保存；
- 出生时间不能晚于占问时间；
- 多选项不得为空、重复或仅有一项。

长期命理问题缺少出生资料时仍可锁定，因为需求规定不能阻止其他术式继续检查；校验器会给出警告，而不是伪造参数。

## 九术适用性

四柱八字、紫微斗数和七政四余当前执行以下硬规则：

- 即时占事：状态为“不支持的问题类型”，禁止把问事时间冒充出生时间；
- 长期命理但缺出生参数：状态为“参数不足”，自动跳过；
- 长期命理且参数完整：四柱和紫微只显示机械候选，七政四余只显示十一曜身份目录并停在“古籍证据不足”；任何一项都不会因为有参数就绕过规则门禁。

其余术式继续独立检查，不会因三种命理术式缺参而终止整次占问。

## 出生时间机械审计快照

有出生参数时，占问锁定事务会同时保存 `BirthTimeAuditSnapshot v10`（v1–v9 仍可读取）：

- 原始北京时间、性别和出生经纬度；
- UTC≈UT1 的 JD、版本化 ΔT 及误差、JD(TT)；
- SPA 均时差、经度校正、总校正和出生真太阳时；
- 距两小时时界的安全状态及额外 5 分钟边距；
- 北京时间零点换日与真太阳时零点换日的机械干支日；
- 真太阳时辰与“五鼠遁”条件时柱候选；
- 同一出生瞬间的前推格里高利历、儒略历与 1582 改革历表示；
- 子时换日传统差异未决状态。
- 立春年柱、节令月柱、双零点日柱和真太阳时辰柱组成的四柱机械候选；
- 每柱天干/地支各自的阴阳五行结构元数据；
- 以日干为日主的年干、月干、时干十神机械身份；日干只标记“日主”；
- 晚子时另存以子初换日候选日干、时干重新计算的明干十神，不选定两套口径之一；
- 晚子时零点换日与子初换日两套平行日柱/时柱，选择状态固定为空；
- 晚子时未决、组合一致性、全部边界安全和规则准入关闭状态。
- 现代官方农历日期候选及其边界安全状态；
- 北京时间与真太阳时两套紫微命宫、身宫、月基宫和十二宫逆布序列，时辰口径不自动选择。
- 现代农历名义年与立春换年两套年干候选；各自顺布十二宫宫干，并与两套时辰形成最多四套命宫纳音及五行局，年干口径也不自动选择。
- 七政与紫气、月孛、罗睺、计都的身份目录、四余五行名义及异名；四余现代天文角色选择、位置、宿度、十二宫、命盘和规则准入均固定关闭。

快照状态固定为 `mechanical_audit_not_natal_chart`。四柱候选只生成三个非日主明干的十神机械身份，不读取地支藏干，不判断十神强弱、旺衰、格局、用神、大运或吉凶；紫微候选只安命身宫、十二宫、宫干与五行局，不生成星曜或断法；七政四余只保存十一曜身份，不生成位置、宫位、命盘或任何裁决信号。

没有出生参数时，快照字段为 `null`。旧 v1–v25 天文快照、BirthTimeAuditSnapshot v1–v9 和紫微审计 v1 继续可读，不补造新增审计数据。

## 完整性与重算

出生审计与占问天文数据一起进入不可修改的原始 JSON 字节哈希。开发者模式可重算并比较。JSON 浮点往返可能产生约 `10⁻¹⁴` 的末位差异，因此数值字段使用 `1×10⁻¹²` 的序列化容差；算法版本、时间字符串、干支、时界安全状态等离散字段仍必须完全一致。超过容差的修改会判为不一致。

## 不二占身份

事件指纹 v3 纳入性别、出生北京时间和出生行政地点。两条长期命理记录的出生身份不同，不会仅因问题文字相近而被认作同一事件；旧指纹保持原值，不静默重写。
