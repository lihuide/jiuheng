# 六爻降雨：清刊《增删卜易》天时全章影印取得

日期：2026-09-29。程序及 Windows 安装包版本仍为 v0.75.0。

## 本轮真正推进了什么

此前 [首条天气流程报告](FIRST_WEATHER_WORKFLOW_2026_09_27.md) 所述“尚无可读取原页”阻断，针对《增删卜易》已解除：从日本国立公文书馆公开馆藏取得清乾隆学耕堂刊本第三册的“天时章第三十五”连续图像。章题位于第 38 幅右页，章节延续至卷三末、第 57 幅右页；第 37 幅仍属前章，第 58 幅是封底。20 幅研究图像实际写入源码资料目录，共 17,767,007 字节，并逐幅核对文件大小、JPEG 头尾及 SHA-256。图像是馆藏 IIIF 服务生成的约 3000 像素宽 JPEG，不冒称原始扫描 JP2。

馆藏目录记载：书名《増刪卜易》，编者李文辉（清），清乾隆学耕堂刊本，六册六卷，索书号“子０５９－０００８”，旧藏者为丰后佐伯藩主毛利高标献上本。目录只精确到乾隆时期，不据此编造刊刻年份。资料由[国立公文书馆馆藏目录](https://www.digital.archives.go.jp/file/1079274)及[第三册 IIIF 清单](https://www.digital.archives.go.jp/api/iiif/4756815/manifest.json)定位；图像沿用该馆的[二次利用说明](https://www.digital.archives.go.jp/secondary-use)，并保留馆藏署名。

完整逐幅清单、文件字节、哈希与采样目视范围见[机器可读影印记录](../data/research/liuyao-weather-naj-facsimile.json)。离线校验程序为 [verify_weather_facsimile.py](../scripts/verify_weather_facsimile.py)。这些图像随本轮源码包提供，普通 Windows 程序不加载它们，也不因此增大原 v0.75.0 安装包。

## 目视核查与仍然不能推断的部分

已目视抽核第 38、39、40、42、44、46、48、50、52、54、55、56、57 幅：章内不仅有父母、妻财、子孙等象征身份，还涉及多动爻、变爻、冲合、当时天候与实占应验。不能把“父母动”或任何单一口诀改写成“必下雨”，也不能把古文中的日、时未经验证地换算成“1 小时内/3 小时内”。本轮未完成 20 幅逐字转录、版面叶码校核、全部例外条件梳理、早期材料及其他可靠版本异文比较。

这部清刊本是有可核原页的历史版本，但不自动具有先秦—汉唐最高证据等级。即使某段文字可读，仍须逐条检查：版本层级、规则完整性、相反案例、与早期权威文献有无冲突、各个机械前提是否真正可计算、应期是否适用于现代用户输入的时间范围。需要与《卜筮正宗》等其他可核版本交叉比对，不能只凭这一部放行。

正式规则库继续为 0 条，九术完整可裁决继续为 0/9。普通界面不能凭这些研究图像输出降雨结论或“当下怎么做”。本轮也没有重编译 Windows 安装包或便携版。

## 下一步单线工作

1. 以已保存的第 38–57 幅逐页转录，记录右/左页、印刷叶码、疑难字和异文；优先抽取“单一地点、指定时段是否下雨”直接相关的段落及其反例。
2. 对照依赖的基础章、早期经典与另一可靠影印本，列出每条候选规则的前提、限制、优先关系、失效条件和应期；无法确定的部分不启用。
3. 完成书目、转录、逻辑、实现四类复核及正例/反例/边界测试后，才生成正式 Rule ID，接入桌面锁题—起卦—结果—时间—建议—保存重放流程。

本轮只通过影印图像字节校验，不把它称为天气占断测试通过。旧的 379 项 Rust 和 15 项 Python 测试是上轮基线，没有因本次资料取得而重算或增加为已通过项。C 盘可用空间已很紧张，本轮不启动占空间的完整 Windows 构建。
