# 太乙主客大小将宫位机械候选审计

本页记录 v0.39.0 在既有“始击、主算、客算”之后增加的四个排盘字段：主大将、主参将、客大将、客参将所在宫。它们只由已经取得的主算、客算确定，不选择积年历元、现代日期或阴阳遁，也不解释囚、格、掩、迫、击、关等关系。

## 大将宫约减

主大将取主算，客大将取客算。程序对 1–40 的置算执行：

```text
个位不为零：大将宫 = 个位
个位为零：  大将宫 = 十位
```

所以 10→1、20→2、24→4、29→9、40→4。这个写法同时保留卷二明文的 10→1、24→4，并把 1–40 的全部输入变成可穷举测试的确定映射。

## 参将宫约减

程序先把大将宫数乘三，再使用同一个约减步骤：

```text
参将宫 = 约减（大将宫 × 3）
```

跨卷锚点为：7→21→1、3→9、9→27→7、4→12→2、5→15→5。卷一时计算例、卷三阳遁第一局和阴遁第一局彼此独立地覆盖了这些结果。

参将“三因”的直接文字仍须取得影印并由第二位复核者闭合；本版只把跨卷结果一致的机械候选写入排盘层，不将其升级为断法证据。

## 中五宫类型隔离

太乙自身按既有候选只行一、二、三、四、六、七、八、九八宫，不入中五。大小将却可由算数约减得到五宫，例如卷三阴遁第一局的主大将、主参将均在五宫。

Rust 核心因此使用独立的 `TaiyiGeneralPalace`（一至九全含）表示大小将，不复用排除中五的 `TaiyiPalace`。这是为了在类型层阻止两套宫域被误混，而不是增加任何五宫解释。
