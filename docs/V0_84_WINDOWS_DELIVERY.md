# 九衡 v0.84.0 Windows 交付

日期：2026-11-13。范围：明确参数的太乙机械候选接入普通排盘记录流程。

## 本次完善

- 新增“太乙机械盘”页面，侧栏与永久记录均可打开，不要求出生参数或六爻随机起法。
- 提供三种明确输入：已知积年；传统年标签与显式选择的开元十二年积年假设；明确阴遁或阳遁的局序。默认不填写年份、不勾选假设、不选择阴阳遁；切换输入类型清空旧值。
- 九宫展示太乙及主客大将、参将。采用太乙自身宫号，上南下北、左东右西：九二七 / 四五六 / 三八一。十六神独立列表标出天目与始击，保留重留与周期位置；显示主客算、计神等已有机械结果。
- 年计展示开门分别加太乙、主大将、客大将的三张独立八门盘。将位中五只停止对应门盘，不擅自寄宫；七十二局候选不混入年计八门。
- 一个问题可保存多个明确参数候选；相同参数重复保存返回已有候选，不覆盖也不重复插入。原占问时间与六爻起法不受影响。
- 新表保存原请求、计算结果、记录身份、保存时间及内容校验；每次重开校验保存内容并按原请求复算，失败时停止显示。保存与去重使用数据库事务，触发器阻止修改和删除。
- 新增复制当前候选及离线 HTML 导出，保留输入假设、范围和中五停盘提示；创建独立文件，不覆盖旧导出。
- 数据库 schema 13 自动升级为 14，仅新增太乙候选表及约束，不改写旧占问和历法快照；顶层历法快照 v30、出生审计 v14 保持原版本。旧记录无太乙候选时显示空状态，不自动补盘。
- 侧栏支持滚动，避免新增入口挤出小窗口可见范围。

本轮复用已有太乙核心算法，没有新设公历转传统年界、运行历元或阴阳遁选择公式。既有证据范围见[年标签桥接](TAIYI_TRADITIONAL_YEAR_EPOCH_AUDIT.md)、[阴阳遁七十二局](TAIYI_DUN_BOARD_AUDIT.md)和[固定开源表比较](TAIYI_OPEN_SOURCE_COUNTS_CROSSCHECK.md)。阴遁传本的 3 处始击、9 处主客算单元格异文，以及固定开源参考 144 局中的 4 局单项主客算差异，继续明示并保留待核。
