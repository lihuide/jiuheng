# 紫微斗数十四主星落支机械审计（v0.74.0）

本版只把已保存的紫微星锚展开为十四主星的相对地支位置。星位不是实际天体坐标，也不携带性格、吉凶或命运解释。普通结果页及综合裁决继续不使用这些候选。

## 材料与边界

[《紫微斗数全书》卷二公共转录](https://zh.wikisource.org/zh/%E7%B4%AB%E5%BE%AE%E6%96%97%E6%95%B8%E5%85%A8%E6%9B%B8/%E5%8D%B7%E4%BA%8C)包含“安南北斗诸星诀”和“安天府图”。前者给出紫微系逆排、天府系顺排及间隔；后者给出寅、申紫府同宫和紫丑府卯等镜像样例。[独立开源实现](https://github.com/wangtz19/Xieji/blob/main/divination/ziwei.py)仅用于交叉核对相对位移，仓库中的星曜批注和断语没有被采纳。

目前只取得公共电子转录，尚未将这两处文字逐字绑定经复核的主版本影印页、文件哈希及异文。因此本层始终标作机械研究候选，不生成正式 Rule ID。

## 机械位置

地支按子至亥编号 0–11。以紫微位置为基准，天机、太阳、武曲、天同、廉贞依次位于 `−1、−3、−4、−5、−8` 宫。天府的位置满足“紫微索引 + 天府索引 ≡ 4（模 12）”；以天府为基准，太阴、贪狼、巨门、天相、天梁、七杀、破军依次位于 `+1、+2、+3、+4、+5、+6、+10` 宫。每一候选恰保存十四颗主星的名称、所属星系、相对位移和落支。

名义农历年与立春年干、北京时间与真太阳时时辰仍形成四套口径。即使星位相同也不擅自选择一种。农历日期、年界或时辰边界不安全时，机械安全状态随紫微星锚关闭；所有候选的解释与规则准入状态固定为否。

## 历史兼容与验证

紫微审计升至 v4、出生审计升至 v12、顶层天文快照升至 v28。v0.73 的 v3/v11/v27 记录原字节可读，缺少十四主星字段时不回填；新记录重算会核对星位，篡改则判不一致。开发者模式与历史页分行显示紫微系和天府系。

测试覆盖寅宫紫府同宫的十四星逐颗位置、天府图十二种紫微落支镜像、旧快照兼容、新快照防篡改以及研究档案不得进入空的运行时规则库。辅煞、四化、三方四正、大限流年、古籍断法和应期仍未实现。
