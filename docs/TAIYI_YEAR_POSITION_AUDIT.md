# 太乙积年定位机械候选审计

本页只说明九衡如何把一个**外部已经给定的正整数积年**约减成太乙所在宫和入宫第几年。它不是完整太乙局，不接受现代日期，也不输出吉凶、应期、行动建议、中间信号或 Rule ID。

## 已固定的传本范围

- 底本标识：Kanripo `KR3g0047`，`BASEEDITION WYG`，即《钦定四库全书》本《太乙金镜式经》。固定提交为 `e3264da2c9f556225e056abe7eade01903b4543e`。
- 卷一 `KR3g0047_WYG_001-4a` 的“积太乙所在法”给出三百六十、七十二、二十四和三年一宫的约减步骤，并说从一宫顺行八宫、不游中五、算外。
- 卷二 `KR3g0047_WYG_002-1b` 至 `2a` 明说三年徙一宫。
- 卷三 `KR3g0047_WYG_003-9b` 至 `14a` 的阳局立成表把边界落成可核对锚点：1–3 局在一宫、4–6 局在二宫，依次为三、四、六、七、八、九宫；24 局在九宫，25 局回一宫。
- 三卷固定转录文件的字节数和 SHA-256 已写入 `data/research/taiyi-year-position-candidates.json`。这固定的是转录文件身份，不等于完成影印复核。

## 程序边界

`taiyi_year_position_from_accumulated_count` 只接受大于零的 `u64`。所有周期都按一基位置计算：

```text
position = ((count - 1) mod modulus) + 1
```

因此 24 算不会错误变成第 0 位；它是九宫第三年，25 算才回到一宫第一年。宫序固定为 `1, 2, 3, 4, 6, 7, 8, 9`，永不进入中五。自动测试覆盖同卷立成表锚点、360/361 边界、1–720 算穷举不变量、零输入和 `u64` 最大值。

返回对象永久标记：未选历元、不是由公历日期推得、未生成完整局式、不可解释、不可生成中间信号、不可进入规则。

## 为什么仍不接受日期

卷一同时保留“四万八百一算”和“一百九十三万七千二百八十一算”两套叙述；公开电子转录在“开元十五年/十二年”处也有差异。再加上全书存在后人增补问题，九衡不能只凭一份电子文本选择历元、岁首和历法换算口径。

目前已经定位 Kanripo 的四库页码标识，但尚未取得并校验对应影像字节。因此本版允许实现与立成表直接一致的纯约减函数，同时继续禁止“现代日期 → 上元积年”。这条边界能防止一个局部正确的宫序函数被包装成看似完整、实际历元未定的太乙排盘。

## 后续放行条件

1. 取得卷一、卷二、卷三对应四库影像，并记录稳定馆藏标识、页码和文件哈希。
2. 人工逐字校对积年、积太乙所在法和阳局立成表，登记全部异文。
3. 用可靠历谱核对开元纪年与干支，解释或排除“十五年甲子”等冲突。
4. 分别考证年计、月计、日计、阳遁時計、阴遁時計，不从年计函数擅自外推。
5. 书目、转录、逻辑、实现四类复核及权威课例边界测试全部通过后，才能另行讨论完整机械盘；断法仍需独立规则证据链。
