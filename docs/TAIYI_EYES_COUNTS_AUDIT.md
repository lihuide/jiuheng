# 太乙始击与主客算机械候选审计

本页记录 v0.38.0 在“外部给定积年→太岁、太乙、天目、计神、合神”基础上增加的三个机械字段：始击（客目）、主算、客算。输入仍然只能是调用方已经给定的一基正整数积年；程序不接受现代日期，不选择积年历元或阴阳遁，也不生成主客大小将、完整局式或任何解释结果。

## 始击（客目）

卷二“推太乙运式法”先说“详何神为始击”，然后给出“以计神加和德宫，求文昌所临宫”。同段前一步把天目用于安置文昌、始击，卷二五将身份又明确文昌为下目、始击为上目。程序因此只做如下可对表的旋转：

```text
始击位置 =（和德索引 2 + 天目本位索引 - 计神支本位索引）mod 16
```

例如第一局天目武德在索引 11、计神寅在索引 3，旋转后始击落索引 10，即大武。卷三第一局客目正作大武。程序保存一基的 `shiji_ring_position` 和规范化十六神身份 `shiji`。

这里的“文昌所临宫”只按上下文用于机械旋转，不据此增加任何文昌或始击吉凶解释。

## 主算与客算

卷二说明：视天目所在求主算，视始击所在求客算；二目在正宫时以该宫本数起算，在间神时从一算起，沿十六位置顺行，累加途中经过的正宫数，到太乙所在宫以前停止。

程序另显式处理“二目与太乙同宫”的边界：直接保留该正宫本数，不绕环一周。卷三第九局天目和德、太乙三宫，主算为三；第十一局天目高丛、太乙四宫，主算为四，均验证这一边界。

卷二自身的算例是太乙九宫、天目大义：大义间神起一，继而地主八、和德三、高丛四，合为十六，与程序结果一致。

这些整数只是式盘机械字段，不是概率、方法分、中间信号或现实胜算。

## 七十二局整表核对

卷三“阳局天目地目计神主客大小将立成”逐行列出一至七十二局。研究档案独立转录三列：

- 客目（始击）72 项；
- 主算 72 项；
- 客算 72 项。

自动测试对每一局分别调用 Rust 实现并逐项比较，不使用程序自行生成的数组作为期望值。另以 1–720 算穷举检查始击位置始终在 1–16，主客算始终在 1–40，且所有规则、信号、解释门禁保持关闭。

## 异文与转录异常

- 卷二十六神身份在巳位作“太神”，卷三表同一位置多作“大神”。程序规范名采用“太神”，研究档案保留“大神”异文。
- 卷二“求始击”句中写“求文昌所临宫”；本候选只依据同段步骤和七十二局整表做可复核的天目旋转，不扩张为断法。
- 卷三第四十一局计神栏公开转录作“戊”，与十二支循环不合。本层不使用该字符；计神继续由卷一公式和其余表行校验。
