# 六爻六神身份机械层审计

## 本版完成范围

`jiuheng.liuyao.received_day_stem_six_spirits.bjt_midnight.v1` 在六次三币、卦象、八宫世应、纳甲干支和六亲身份均完成重放之后，按存档占问日干为本卦六爻轮排青龙、朱雀、勾陈、螣蛇、白虎、玄武。

本版明确使用已经固化在占问天文快照中的“北京时间午夜换日干支日候选”。这项口径写入算法版本和开发者审计，不会静默换成子初换日或真太阳日界。

## 起例与方向

六神固定循环为：青龙 → 朱雀 → 勾陈 → 螣蛇 → 白虎 → 玄武。

- 甲乙日初爻起青龙；
- 丙丁日初爻起朱雀；
- 戊日初爻起勾陈；
- 己日初爻起螣蛇；
- 庚辛日初爻起白虎；
- 壬癸日初爻起玄武。

从初爻向上爻顺排，一个六爻盘恰好各出现一次。程序对十天干全部起例以及 64 卦 × 10 天干共 3,840 个逐爻案例进行穷举。

## 证据边界

《增删卜易·六神章第十八》的电子转录保存了六组日干从初爻至上爻的完整表；《易隐·序》的六神所属和起六神法目录用于名目交叉核验。

当前来源仍是公共电子转录，对应影印页尚未固定为本地不可变字节并计算 SHA-256。玄武/元武、螣蛇/腾蛇/滕蛇等异文及传承层次也未完成逐页校勘。因此这里只建立排盘身份候选，不生成正式 Rule ID。

## 历史复现与旧记录

六神不新增数据库字段。历史重放先验证原起卦材料和不可变天文快照，再从快照读取北京时间午夜换日的日干，依固定算法派生六神。

旧记录如果没有保存可核验日干，六神审计明确缺席并退回显示六亲机械表，不会用当前时间补算或改写历史。

## 明确未实现

以下全部保持失败关闭：

- 六神的吉凶、人物、疾病、生死或事件解释；
- 伏神；
- 用神选择、月建、日辰、旬空与旺衰；
- 动变关系与应期；
- 中间信号、结论、行动建议和正式 Rule ID；
- 子初换日与真太阳日界的六爻规则准入。

## 自动护栏

- 十天干逐组核对完整六爻表。
- 穷举 64 卦 × 10 天干，验证每盘六神各出现一次。
- 研究 JSON 与 Rust 输出对拍全部 3,840 个逐爻案例。
- 历史重放只允许使用同一占问已保存且通过哈希核验的日干。
- 正式规则种子继续为空，解释、信号、应期、建议与规则资格必须为否。
