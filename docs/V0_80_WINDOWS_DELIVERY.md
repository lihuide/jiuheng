# 九衡 v0.80.0 Windows 交付

日期：2026-11-12。版本定位：六爻排盘记录试用版。

## 本次用户可见更新

- 新增普通界面的六爻排盘报告，将本卦、变卦、六条爻的动静、世应、六亲、纳甲、六神集中展示，说明动爻的阴阳变化。
- 起法完成后可直接进入报告；历史记录也能打开同样的报告。每次打开均从 SQLite 读取并重新核对原始起法材料。
- 支持复制文字记录，以及生成可离线打开、可用浏览器打印的 HTML 报告。报告包含锁定问题、时间、地点、结构说明和记录编号；每次导出使用新文件名，不覆盖旧报告。
- 历史搜索覆盖全部本地记录，支持问题、主体、对象、目标事件、地点、锁定日期和编号；每页最多 50 条，支持前后翻页。
- 首页增加使用步骤，窗口和报告明确标注试用范围。未完成六次的记录不显示核对成功，材料核对失败不生成报告；临时内存模式停用文件导出并保留数据不可持久化提示。

## 范围与进度

正式古籍规则 0 条，九术完整可裁决 0/9。原始 16 项一级需求仍为 5 项通过、9 项进行中、2 项受阻；本轮完成排盘记录流程，不据此改变完整占断需求的验收状态。降雨候选暂缓作为首发门槛，原因与重新启动条件见 [范围评审](RELEASE_SCOPE_0_80.md)。

## 验证记录

本轮累计 398 项 Rust 测试通过：完整工作区原 397 项通过后，补充普通模式打开历史排盘的界面渲染检查，桌面 8 项再次全部通过。覆盖数据库关闭重开后报告一致性、网页转义、导出不覆盖、导出失败、未完成/不存在记录和全文搜索分页。20 项 Python 打包工具测试通过；最终格式检查及严格静态检查通过。

本机构建出现内存不足后，将默认构建并发设为 1，发布配置关闭跨库链接优化并使用 8 个代码生成单元；保留体积优化、符号裁剪和正式 release 模式。该调整降低构建内存需求，不改变排盘算法。

Windows 程序已在 D 盘隔离数据目录启动并创建数据库。使用同一正式程序生成的 SmokeTest 安装包完成安装、启动、建库和卸载；测试包关闭注册项和快捷方式写入，以避免改变现有安装。正式安装包正常生成，注册项和快捷方式未在本轮操作验收。

本机 Windows 截图接口返回 `SetIsBorderRequired failed: 不支持此接口 (0x80004002)`，文字接口能确认程序窗口标题，但无法读取图形界面内的控件。因此没有宣称完成逐按钮实机验收；已通过的界面检查为 egui 渲染测试，确认普通模式在没有当前新占问时仍能从历史加载报告并呈现六条爻、复制和导出入口。
