# 六爻进神、退神动变原始身份审计

## 本版完成范围

`jiuheng.liuyao.received_seven_explicit_progress_retreat_pairs.v1` 只检查实际动爻的“本卦纳甲地支 → 同爻位变卦纳甲地支”，并标注当前已核公开电子转录明确列出的进神、退神身份。

静爻不生成虚构的变支记录。未命中明确目录的动变仍会保存，但身份为“未分类”。这一层不判断进而有功、退而无力，也不生成旺衰、应期、吉凶、总分或行动建议。

## 当前明列目录

| 身份 | 当前明确采用的七组有向支对 |
|---|---|
| 进神 | 亥→子、寅→卯、巳→午、申→酉、丑→辰、辰→未、未→戌 |
| 退神 | 子→亥、卯→寅、午→巳、酉→申、辰→丑、未→辰、戌→未 |

退神目录正好是上述七组进神方向的逆向。程序对 12×12 共 144 种有向地支变化逐项检查，只有这 14 种方向得到进神或退神身份。

## 为什么没有自动补成八组

《增删卜易》卷二“进神退神章第二十九”的当前公开电子转录列出七进、七退，但没有出现“戌化丑”和“丑化戌”。《易隐》的当前公开电子转录则只列六进、六退，又没有列“辰化未”和“未化辰”。《卜筮正宗》《卜筮全书》《易冒》的公开转录能交叉支持若干具体方向，却不足以单独补齐完整八组表。

因此本版明确采用保守策略：

- 戌→丑保持“未分类”，不自动认作进神。
- 丑→戌保持“未分类”，不自动认作退神。
- 待主版本影印页、异文和版本谱系复核后，才决定是否发布新算法版本。

这不是断定两组一定不属于进退，而是承认当前证据没有达到九衡的发布门槛。

## 自动验证

- 七组进神与七组退神逐项对拍研究记录。
- 每组进神的逆向必须正好命中退神，反之亦然。
- 戌→丑、丑→戌必须保持未分类。
- 144 种有向地支组合只能有 14 种被分类。
- 穷举 `4^6 = 4,096` 种六七八九爻型组合。
- 只为实际六爻、九爻生成记录，合计验证 12,288 条动变观察。
- 每条身份都从本支、变支重新计算；静爻不生成记录。
- 新起卦、历史页和一键重放调用同一个核心函数。
- 正式规则种子仍为空，所有解释和裁决开关必须保持关闭。

## 古籍候选与边界

- 《增删卜易》卷二“进神退神章第二十九”：当前七进、七退目录的直接候选来源。
- 《易隐》“进神退神”条：提供六进、六退的异文/传承差异警告。
- 《卜筮正宗》：交叉支持申化酉、酉化申等例。
- 《卜筮全书》：交叉支持寅化卯、巳化午、酉化申、子化亥等例。
- 《易冒》卷二“进退章第十六”：交叉支持亥变子、未变辰等方向，并警示效力须另看条件。

目前均为公共电子转录，尚未完成主版本影印页、本地字节、SHA-256、异文和版本谱系闭环，所以只进入机械研究层，不能生成正式 Rule ID。

研究档案：`data/research/liuyao-progress-retreat-candidates.json`。

## 明确关闭

- 不把进神身份解释为前进、成功、增强或吉。
- 不把退神身份解释为后退、失败、减弱或凶。
- 不选择用神，不计算旺衰、月破、日辰、空墓、合冲对进退的效力。
- 不输出应期、中间信号、总分、结论或行动建议。
- 不把公共电子转录、现代常见表或开源实现替代影印底本与四类复核。
