# 太乙主客算开源对照报告

核验日期：2026-09-27。程序基线：v0.75.0；本次为源码研究/验证增量，未发布新桌面版本。

## 本次实际完成

将用户提供的 `kentang2017/kintaiyi` 从“登记参考项目”推进到一项可重复的静态算数表比较。参考 commit 固定为 `626d8a5bd0f707fec2ed613c83d4b6611f56441d`；[源文件](https://github.com/kentang2017/kintaiyi/blob/626d8a5bd0f707fec2ed613c83d4b6611f56441d/src/kintaiyi/config.py) 的字节数为 182,460，SHA-256 为 `8effd0484865256592602be193fc7b7fabc761dbc9bbd2e0e0b74dd338ceebb0`，与既有固定源清单闭合。

只静态读取 `find_cal` 的 `yangcal`、`yingcal` 字面量，每张表 72 行；保存主算与客算，不使用定算、断语、权重、应期或建议。参考模块包含顶层 pickle 读取，因此**不导入模块、不执行任何第三方函数**。自写提取器仅用 `ast.parse` 与 `ast.literal_eval`，拒绝函数调用、非整数、越界值、错误行数、重复定义和重复赋值。

参考数据只编入 Rust 测试/研究示例，不编入桌面应用、核心库运行路径、规则种子或 SQLite 规则。完整第三方执行门禁与六组未来时间起局契约保持关闭。

## 对照结果

九衡逐次调用独立 Rust 函数 `taiyi_seventy_two_board_frame_from_count`，输入为明确的阳遁/阴遁及 1–72 局序：

| 指标 | 实测结果 |
|---|---:|
| 比较局数 | 144 |
| 比较主客算值 | 288 |
| 两值均一致的局 | 140 |
| 一致的数值 | 284 |
| 存在差异的局/数值 | 4 / 4 |

逐格差异如下（不是自动修正清单）：

| 遁 | 局序 | 字段 | 九衡通式值 | 开源字面量值 |
|---|---:|---|---:|---:|
| 阳 | 44 | 主算 | 33 | 23 |
| 阴 | 10 | 客算 | 34 | 24 |
| 阴 | 39 | 主算 | 37 | 27 |
| 阴 | 61 | 客算 | 12 | 22 |

四项均表现为十位差异，但**不能因此断言谁错**。九衡既有《太乙金镜式经》卷二通式/卷三电子表候选支持九衡这四个值；影印逐字核验和独立复核尚未完成。保留两值，下一步回溯这四处卷页，不以开源表孤值覆盖通式。开源输出不是第二份古籍证据。

288 格一致性不是术数准确率；140/144 也不是项目完成百分比。这次未验证日期到局序、历元、冬夏至选遁、定算、完整局式、格局解释、应期或行动建议。
