# 紫微斗数命宫、身宫与十二宫机械审计

## 本版边界

0.24.0 只加入一层可复现、无解释的紫微斗数机械候选：从出生农历月与出生时支计算命宫、身宫，再从命宫逆布十二宫。算法版本为 `jiuheng.ziwei.received_month_hour_life_body_twelve_palaces.v1`，状态为 `mechanical_palaces_only_no_stars_interpretation_or_runtime_signals.v1`。

本层不计算五行局、紫微星、十四主星、辅曜煞曜、四化、庙旺、大小限、流年、吉凶、应期或任何中间信号。紫微插件因此仍不参与综合裁决。

## 传本文字与交叉算例

《紫微斗数全书》卷二的电子转录给出以下机械步骤：

1. 从寅宫起正月，顺数至出生月；
2. 以出生月所在宫为子时，逆数至出生时安命宫，顺数至出生时安身宫；
3. 闰月按下月处理；
4. 从命宫开始，依次将命、兄弟、妻妾、子女、财帛、疾厄、迁移、奴仆、官禄、田宅、福德、父母十二宫逆布。

转录中的正月示例分别得到：子时命身都在寅，丑时命在丑而身在卯，寅时命在子而身在辰。

晚清俞樾《游艺录》的可检索 OCR 另载“二月辰时”算例：二月落卯，从卯逆数至辰时得命在亥，顺数得身在未；还说明子、午时命身同宫，并用命在子时的兄弟在亥、妻妾在戌说明十二宫逆布。该算例与程序公式互相独立地吻合。

相关来源、URL、馆藏线索和当前证据限制保存在 `data/research/ziwei-life-body-palace-candidates.json`。电子转录与 OCR 只用于机械候选和交叉核对；在主版本影像页、校验值和逐字复核闭合前，它们不能产生正式 Rule ID。

## 计算约定

- 地支索引固定为子 0、丑 1，依次至亥 11；寅为月序起点。
- 非闰月的月基宫为 `寅 + 月号 - 1`。
- 普通闰月依传本文字暂按下月处理；闰十二月涉及跨年而所核文字未说明，程序失败关闭。
- 命宫为“月基宫减时支索引”，身宫为“月基宫加时支索引”，均按十二取模。
- 十二宫从命宫起，按传本次序逐宫逆行。
- 界面现代化显示“夫妻宫”，但审计记录同时保留传本标签“妻妾”。

## 北京时间与真太阳时

所核文字没有解决现代出生记录应采用北京时间时支还是真太阳时时支。程序不擅自选择，而是始终并列保存：

- 北京时间两小时时支候选；
- 出生地经度与均时差校正后的真太阳时时支候选。

两套候选各自保存时界安全状态、命宫、身宫、月基宫和完整十二宫序列；`selected_hour_convention` 固定为空。即使两套结果偶然相同，也不代表口径争议已经解决。

## 农历口径与快照兼容

输入月号来自九衡现有的现代官方农历日期候选。它只适用于现代工程审计，不代表历代历法的一套统一反推。农历日期边界不安全时，紫微候选会保留警告并关闭规则准入；日期候选无法形成时，本层自动跳过。

0.24.0 的出生审计为 `BirthTimeAuditSnapshot v5`、顶层天文快照为 v15。0.25.0 加入宫干/五行局后分别升级到 v6 和 v16；旧顶层 v1–v15、出生审计 v1–v5 和紫微审计 v1 仍按原 JSON 读取，不会补造历史命盘或改写旧哈希。

## 自动验证与禁止事项

测试覆盖传本三个正月示例、俞樾二月辰时示例、十二宫方向、闰月作下月、子午命身同宫、非法月号与闰十二月失败关闭，以及北京时间/真太阳时双候选。研究门禁还会强制检查：

- `runtime_rule_seed_allowed` 必须为 `false`；
- `interpretation_eligible` 必须为 `false`；
- 时辰口径不得自动选择；
- 正式规则种子包必须继续为空。

只有主版本、原文定位、异文、时辰与历法口径、星曜排布及解释规则分别完成正式证据门禁后，紫微斗数才可能从“仅排盘”进入可裁决状态。
