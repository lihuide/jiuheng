## 为什么“邻位”与“击迫名称”分开

既有十六位环已经固定为：

```text
地主 → 阳德 → 和德 → 吕申 → 高丛 → 太阳 → 太炅 → 太神
→ 大威 → 天道 → 大武 → 武德 → 太蔟 → 阴主 → 阴德 → 大义
```

太乙只处在八个正宫，正宫在该环上相隔两个位置；两正宫之间为辰位。因此，任何十六神相对太乙只有四种与击迫定义相关的近邻几何：

| 程序值 | 机械含义 |
|---|---|
| `plus_one_interstitial` | 固定环序 `+1` 的相邻辰位 |
| `minus_one_interstitial` | 固定环序 `-1` 的相邻辰位 |
| `plus_two_principal_palace` | 固定环序 `+2` 的相邻正宫 |
| `minus_two_principal_palace` | 固定环序 `-2` 的相邻正宫 |

卷三以“前、后”和“内、外”命名击迫，但当前固定文本没有为程序所采用的数组正方向提供足以独立排除反向解释的锚点。直接把 `+` 命名为“前”或“后”会把实现约定冒充古法。因此程序只保存上述四个无方向值：

```text
shiji_near_taiyi_geometry
tianmu_near_taiyi_geometry
near_ring_geometry_computed = true
```

`None` 在新记录中表示不在上述四个邻位；历史 v1 关系快照则通过 `near_ring_geometry_computed = false` 表示当时根本未计算，两者不会混同。

## 已实现的“对”

卷三“推对法”直接以文昌将冲太乙宫为“对”。在当前机械对象中，文昌对应天目；“冲太乙宫”按既有八正宫对宫处理，即十六位环相隔八位：

```text
tianmu.ring_index == taiyi.opposite.ring_index
    → tianmu_opposes_taiyi = true
    → opposition_classified = true
```

这与“格”严格分开：“格”的主语是客目及客方大小将，“对”的主语仅按本段文字取文昌（天目）。任何相邻解释文字均未进入代码。

## 仍然关闭的三类关系

- `strike_classified = false`：已保存始击邻位，但没有选择前后、内外方向，不能输出前击、后击、外宫击或内宫击。
- `pressure_classified = false`：迫法同时涉及上下二目、四将及“上目无迫”等说明；单独知道天目的邻位不足以声称完成迫法。
- `barrier_classified = false`：关法中“相宫齐”“同宫数齐”的配对主体和宫数口径尚未闭合，不能把普通同宫比较冒充“关”。

四郭固、四郭杜、执提、提挟等复合格局也继续关闭。
