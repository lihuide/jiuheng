## 状态定义

- `可用`：算法、原文、版本与测试均已通过复核，可参与裁决。
- `仅排盘`：只实现可验证的数学排盘，不输出断法信号。
- `研究未完成`：规则证据尚未完整录入或复核，禁止参与。
- `不适用`：古籍依据不支持当前问题类型。

当前按用户原始 16 项一级需求逐项验收：5 项已通过、9 项进行中、2 项未通过/受阻；这些项目不等权，不换算百分比。正式古籍规则仍为 0 条，九术完整可裁决仍为 0/9。分项证据见 [项目逐项验收清单](PROJECT_ACCEPTANCE_CHECKLIST.md)。
