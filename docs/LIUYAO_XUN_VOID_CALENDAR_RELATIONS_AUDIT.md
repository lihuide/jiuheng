# 六爻旬空、月日支位与五行方向原始关系审计

## 本版完成范围

`jiuheng.liuyao.xun_void_month_day_branch_five_element_raw_relations.v2` 从锁定占问的日辰确定所属六旬及该旬十干没有配到的两个地支，把月建、日辰与本卦六爻、实际动爻变后爻的地支做直接相等和六冲对支比较，并记录月建/日辰五行相对爻五行的方向关系。

本层只回答“是不是同一个地支、是不是十二支相隔六位、是不是本旬未配到的两个支、两种五行是谁生谁或谁克谁”。它不回答这些结构是否产生力量、是否有利、是否填实、是否出空，也不参与综合裁决。

## 六旬未配支表

| 旬首 | 旬中未配支 |
|---|---|
| 甲子 | 戌、亥 |
| 甲戌 | 申、酉 |
| 甲申 | 午、未 |
| 甲午 | 辰、巳 |
| 甲辰 | 寅、卯 |
| 甲寅 | 子、丑 |

算法不依赖手写日期字符串：日辰在六十甲子中的零基序号除以十确定旬号，再从旬首开始检查十个连续干支，最后两个未配地支作为结构候选。

## 每爻保存的原始观察

- 爻支是否与月建同支。
- 爻支是否为月建的六冲对支。
- 爻支是否与日辰同支。
- 爻支是否为日辰的六冲对支。
- 爻支是否属于当前旬的两个未配支。
- 月建五行相对爻五行的方向：同五行、月建生爻、爻生月建、月建克爻或爻克月建。
- 日辰五行相对爻五行的方向：同五行、日辰生爻、爻生日辰、日辰克爻或爻克日辰。
- 数据层属于本卦明爻，还是实际动爻的变后爻。

本卦六爻全部检查；只有实际发动的六爻或九爻才增加变后观察。伏神暂未并入本层，防止在飞伏作用尚未闭合时误导使用者。

## 自动验证

- 六个旬首及十二个未配支与研究记录逐项对拍。
- 每个旬内十个干支日必须返回同一旬首和同一对未配支。
- 穷举 60 个干支日与 64 个本卦，共检查 23,040 条本卦爻支观察。
- 每条“同月建、月建对支、同日辰、日辰对支、旬中未配支”标记都重新按地支比较验证。
- 穷举五种五行两两组合的 25 个方向格；同类、源生目标、目标生源、源克目标、目标克源各恰好 5 格，反向关系逐格互换验证。
- 每条月建/日辰五行关系都从保存的地支五行重新计算，禁止读取结论文本反推。
- 变后观察数量必须等于实际动爻数量，爻位必须保持一致。
- 新起卦、历史页和一键重放使用相同的核心函数。

## 证据边界

《卜筮全书·通玄妙论》电子转录列出“甲子旬中戌亥空”以及“正月建寅、申为月破”的直接例子；《协纪通义》电子转录提供六个旬首与未配支完整表；《卜筮正宗》传本卦例把空亡、月建、日辰、爻支并列显示；《卜筮全书》卷一“启蒙节要”用于交叉核对五行相生相克及生我、我生、克我、我克、比和的方向名义。

这些来源尚未完成对应影印页的本地字节固定、SHA-256、异文和版本谱系复核。尤其旬空、月破、日冲、生克对动爻、静爻、伏神和变爻的效力及例外非常复杂，所以本版刻意使用“旬中未配支”“对支”“方向关系”等中性描述。

## 明确关闭

- 不判断旬空是真空、假空、动空、冲空、填实或出空。
- 不判断月建对支是否形成有效月破，也不判断出破、填破或合破。
- 不判断日辰对支是否形成暗动、日破、冲实或填实。
- 只记录月日与爻的五行生克方向，不判断是否真正发生生克、力量大小或结果；冲合、刑害、三合六合的效力仍不计算。
- 不选择用神，不评旺衰，不生成应期。
- 不生成中间信号、结论、行动建议或正式 Rule ID。
