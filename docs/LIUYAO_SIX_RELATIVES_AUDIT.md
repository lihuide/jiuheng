# 六爻六亲身份机械层审计

## 本版完成范围

`jiuheng.liuyao.received_palace_five_element_six_relatives.v1` 在六次三币材料、六十四卦结构、八宫世应和传世纳甲干支均完成确定性重放之后，为本卦六爻派生父母、兄弟、子孙、妻财、官鬼身份。

计算只使用两个已保存结构量：本卦所属八宫的五行，以及每爻纳甲地支的五行。问题类别、问句内容、随机点击和日期都不会改变同一卦的六亲表。

## 机械关系

以卦宫五行为“我”：

- 与我比和为兄弟；
- 生我为父母；
- 我生为子孙；
- 克我为官鬼；
- 我克为妻财。

由此形成五类完整表：乾兑属金、坎属水、坤艮属土、离属火、震巽属木。程序穷举五种宫五行与五种爻五行的 25 个组合，不用默认分支猜测身份。

这里的“父母、兄弟、子孙、妻财、官鬼”只是传世装卦名目。它们尚未映射为现实人物、事项、吉凶、得失或建议。

## 证据边界

本轮用《增删卜易·六亲歌章第五》的五类完整表作为直接候选表，以《易隐·序》和《卜筮全书·启蒙节要》所载生克定义交叉核验。三种来源当前均为公共电子转录。

对应影印页尚未固定为本地不可变字节并计算 SHA-256，版本谱系和异文也没有完成逐页校勘。因此本版只建立可复现的“传世六亲身份机械候选”，不生成正式 Rule ID。来源、完整 25 格表、限制与禁用项保存在 `data/research/liuyao-six-relatives-candidates.json`。

## 历史复现与界面

六亲表不新增数据库字段，也不改写旧记录。历史一键重放先校验原六次随机材料、主种子、转录哈希和卦象，再按固定算法依次派生八宫、世应、纳甲干支及六亲。底层材料不一致时派生停止。

普通起法页只提示机械表已经生成。开发者模式和历史重放可逐爻查看爻位、上下卦、纳甲干支五行、六亲与世应。

## 明确未实现

以下全部保持失败关闭：

- 六神与伏神；
- 用神选择与现代问题对象映射；
- 月建、日辰、旬空、旺衰；
- 动爻关系、进退化、应期；
- 吉凶、成败、中间信号、结论和行动建议；
- 正式 Rule ID 与综合裁决参与资格。

## 自动护栏

- 五种宫五行 × 五种爻五行共 25 个组合逐项对表。
- 乾、坤本宫卦逐爻核对六亲序列。
- 穷举 64 卦、384 爻，验证每爻恰有一个六亲身份。
- 研究 JSON 的完整 25 格表与 Rust 输出逐项对拍。
- 历史重放证明必须同时包含八宫、纳甲和六亲审计。
- 正式规则种子必须继续为空；六神、用神、旺衰、解释、信号和规则资格必须为否。
