# 九衡 v0.76.0：首条降雨流程范围门禁与 Windows 交付

日期：2026-09-29。

## 这版程序实际新增

- 跨平台 Rust 核心新增首条降雨流程的确定性参数审计：只把明确询问“是否下雨”、单一目标且可换算目标时间的天气问题纳入研究范围。它不解释卦、不预测天气，也不放行古籍 Rule ID。
- “1小时后／一小时以后”换算为单一北京时间点；“3小时内／未来三小时内／今日内”换算为有起止的北京时间区间。限制在 1–72 小时或 1–7 天；无法明确换算的“近期”、零时长、过宽范围和比较范围均失败关闭。天气占问空目标时间不能锁题。
- 原固定天气类别过去一律映射到 `WeatherRain`。本版在数据库规则执行及最终裁决前再验一次首条降雨范围：刮风、雨雪混问、雨量问题、原文没有“雨”、模糊时间和多选项均不能借旧分类触发降雨结果。即使历史记录里保留旧分类，也无法绕过最终裁决门禁。
- 中文桌面输入页给出首条流程的填法；开发者模式显示范围算法版本、是否符合、拒绝原因及换算后的目标时间。符合参数范围**不等于**可以出古法结论。

清乾隆学耕堂刊本《增删卜易》第三册“天时章第三十五”20 幅图像及逐幅哈希沿用[原页研究记录](LIUYAO_WEATHER_FACSIMILE_2026_09_29.md)。第 43 幅左页可见一条旧注随后被作者以实占不验质疑；它被列为待排除候选，不据此制造“久雨不止”应期。完整逐字校勘、早期文献对照、相反条件及四类复核仍未完成。
