# 《周易》六十四卦结构目录审计

## 本版结论

0.23.0 新增三种《易》类起法共用的六十四卦机械身份目录。算法版本为 `jiuheng.zhouyi.received_hexagram_structure.v1`，状态为 `mechanical_identity_only_no_judgment_text_or_interpretation.v1`。

目录只把已经生成的六爻阴阳位图映射为：

- 下卦与上卦；
- 传本第一至第六十四卦序号；
- 简体中文卦名；
- U+4DC0 至 U+4DFF 的 Unicode 卦符；
- 本卦与变后卦的结构身份。

它不读取卦辞、爻辞、彖、象，不计算互卦、纳甲、六亲、世应、体用、生克、吉凶或应期，不产生中间信号，也不能进入综合裁决。

## 位图方向

项目固定使用“初爻在最低位”的六位整数：

```text
bit 0 = 初爻
bit 1 = 二爻
bit 2 = 三爻
bit 3 = 四爻
bit 4 = 五爻
bit 5 = 上爻
1 = 阳，0 = 阴
```

低三位组成下卦，高三位组成上卦。八卦位图固定为：

| 卦 | 自下而上位图 |
|---|---|
| 乾 | `111` |
| 兑 | `011` |
| 离 | `101` |
| 震 | `001` |
| 巽 | `110` |
| 坎 | `010` |
| 艮 | `100` |
| 坤 | `000` |

该约定同时服务六爻三币、蓍草十八变和梅花年月日时起卦。上一版梅花固定向量 `011101→011100` 由此明确读作“上兑下离的革卦，初爻变为上兑下艮的咸卦”。它不是“睽”；自动测试专门锁住此上下方向，防止显示层倒置。

## 目录来源与用途边界

- 中国哲学书电子化计划《周易》列出乾、坤、屯、蒙至既济、未济的传本次序与卦名。
- 维基文库《周易》六十四卦速查表提供乾、兑、离、震、巽、坎、艮、坤两轴的上下卦矩阵，适合核对位图方向；它是现代整理表，不作为古籍影印证据。
- Unicode 17.0 官方名称表把第一至第六十四卦连续编码为 U+4DC0 至 U+4DFF；程序因此使用 `U+4DBF + 传本序号`，不手工维护另一套字符表。

机器可读研究边界见 `data/research/zhouyi-hexagram-structure-catalog.json`。该档案的 `runtime_rule_seed_allowed` 固定为 `false`。

## 名称规范

中文界面采用简体字，如“兑、离、归妹、既济”。专名“无妄”和“遯”按所核传本文本保留，不按现代字面擅改。Unicode 符号仅是辅助标识；即使用户字体不能显示该符号，中文卦名、序号、上下卦和六位位图仍完整显示。

## 完整性测试

自动测试遍历全部 64 个六位值并验证：

1. 每个值都能重构原上下卦和原六位值；
2. 传本序号恰好覆盖 1 至 64，且无重复；
3. 64 个中文卦名互不重复；
4. Unicode 码位恰好覆盖 U+4DC0 至 U+4DFF；
5. 乾、坤、屯、泰、否、既济、未济的方向锚点正确；
6. 64 至 255 的输入全部失败关闭；
7. 三种起法仍先通过原有转录和重放校验，再派生结构身份。

## 持久化与兼容

六爻和蓍草历史记录已经不可变保存六位本卦、变后卦、原始操作转录与哈希；梅花记录在天文快照中保存同样的六位结构。因此 0.23.0 不改写旧数据库，也不伪造新字段，而是在读取并通过原算法重放后确定性派生卦名。历史字节、哈希和旧算法版本保持不变。

正式规则种子包仍为空。完成“卦叫什么”不等于完成“卦怎样断”。
